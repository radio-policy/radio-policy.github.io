# 요약
정보통신망 명예훼손죄 형량을 사실적시 5년·5천만원, 허위사실 10년·1억원 이하로 상향하는 법안이며, 대안반영폐기로 처리됐다.

# 제안이유
온라인상 특정 집단·개인에 대한 혐오·비방 게시물이 무분별하게 유통되면서 사생활 침해·명예훼손 피해가 급증하고 있고, 이로 인한 극단적 선택 사례가 이어지고 있어 형량을 강화하려는 취지다.

# 주요내용
- 사실적시 명예훼손을 5년 이하 징역 또는 5천만원 이하 벌금으로 상향한다.
- 허위사실 명예훼손을 10년 이하 징역, 10년 이하 자격정지 또는 1억원 이하 벌금으로 상향한다(안 제70조제1항 및 제2항).

# 통신사업자 영향
- 직접 의무 조항은 없음 — 간접 영향: SK텔레콤 계열 미디어·커뮤니티 서비스의 게시물 관리 리스크가 커져 콘텐츠 모니터링 강화 유인이 될 수 있음.
- 대안반영폐기로 원안 자체는 폐기됨.

# 처리 현황
- 발의: 2025-03-12, 김예지의원 등 10인
- 단계: 대안반영폐기 (국회 계류 — 확정 법령 아님)
