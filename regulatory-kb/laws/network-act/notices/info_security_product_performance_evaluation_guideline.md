# 요약

「정보보호산업의 진흥에 관한 법률」 제17조 및 같은 법 시행령 제10조에 따라 **정보보호제품 성능평가**의 방법·절차 및 **성능평가기관 지정**에 필요한 세부사항을 정한 지침이다(제1조). 성능평가 관련기관은 **과학기술정보통신부장관·한국인터넷진흥원(KISA)·성능평가기관·기술심의위원회**로 구분되며(제3조), 성능평가기관은 유효기간 **4년**으로 지정받고 평가자는 **수습→주임→선임** 3단계 자격체계로 관리된다.

# 적용 범위

- 대상: 신청인이 성능평가를 신청하는 정보보호제품 전반, 성능평가기관으로 지정받으려는 법인.
- 전자정부법시행령 제69조제1항제1호의 **안전성 검증 대상 제품**은 세부기준에 국가정보원 **사전 동의**가 필요(제8조제4항).
- **재검토기한**: 2018년 1월 1일 기준 매 3년째 12월 31일까지(제26조) — 가장 최근 시한은 2026.12.31., 다음 시한은 **2029.12.31.**

# 주요 내용(구조화)

**제2장(제3조~제7조) 성능평가 체계**
- **제4조(과기정통부장관)**: 운영지침 고시·국가정책 결정, 평가기준 수립, **성능평가기관 지정·취소**, 보안관리 실태점검. 기술적 사항 검토·서류 확인 등은 KISA에 대행 가능.
- **제5조(KISA)**: 지정신청 접수, 지정요건 심사, 대행 업무 수행. 필요 시 평가팀 구성해 직접 성능평가 가능.
- **제6조(성능평가기관)**: 성능평가 수행, 결과서 작성·제공, 자체운영규정 수립.
- **제7조(기술심의위원회)**: 제품 분류별 위원회, **10인 이내**(국가정보원장 선정 전문가 포함 가능), 임기 **2년**(연임 가능), 위촉장은 별지 제1호서식.

**제3장(제8조~제14조) 평가 방법·절차**
- **제9조(평가 신청)**: 별지 제2호서식 신청서 + 성능평가 신청 제품·제품설명서·사용자 취급설명서. 성능평가기관은 접수 즉시 접수증 발급, **신청 접수 후 7일 이내** 평가계약 체결(제출물 미비 보완 미이행 시 거부 가능).
- **제10조(수행계획서)**: 별지 제3호서식, **계약체결일로부터 7일 이내** KISA 제출.
- **제12조(평가 중단)**: 계약서 명시 사유 발생 시 중단 가능, 사유를 신청인·KISA에 문서 통보 후 조치 요청, 미이행 시 계약 해지.
- **제13조(평가 종료)**: **종료 후 10일 이내** 별지 제4호서식 결과서를 KISA 제출. 위원회 심의·의결 전 신청인 열람 요구 시 허용 의무.
- **제14조(결과서 제공)**: 위원회 심의·의결 후 신청인에게 제공. 부득이한 경우 서면 심의·의결 가능.

**제4장(제15조~제18조) 성능평가기관 지정·취소**
- **제16조(지정절차)**: 별지 제5호서식 신청서 + ISO/IEC 17025 국제공인시험기관 인정서, 평가자 자격 증명서, 사무·시험공간 평면도, 설비 목록서 등 8종 서류를 **KISA 접수 → 과기정통부장관 제출**. 행정정보 공동이용으로 법인 등기사항증명서 확인. **지정 유효기간 4년**.
- **제17조(재지정)**: 유효기간 만료 **3개월 이전까지** 신청, 지정 절차 준용.
- **제18조(지정 취소)**: 거짓·부정한 방법 지정, 지정취소 요청·폐업, 지정요건 미충족, 고의·중과실 평가결과 산출, **신청인 지적재산권 정보의 제3자 유출** 시 기술심의위원회 심의를 거쳐 취소.

**제5장(제19조~제22조) 평가자 자격**
- **제19조(구분)**: 선임평가자(주임 취득 후 3년·9회 이상), 주임평가자(수습 취득 후 1년·3회 이상 등), 수습평가자(별표3 학력·경력 요건 + 양성교육 수료·시험 합격).
- **제21조(유효기간)**: **3년**, 연 1회 이상 보수교육 이수 의무, KISA가 3년마다 연장 심사.
- **제22조(자격취소)**: 허위서류, 고의·중과실 평가결과 산출, 부당 금품수수, 정보누설, 자격유지기준 미충족 시 취소.

**제6장(제23조) 평가 비용**: 인건비+직접경비+제경비+기술료로 산정(별표4). 우수 정보보호기업 지정 시 비용 감면 지원 가능.

**제7장(제24조~제26조) 보칙**: 보안관리 실태점검 **연 1회 이상**(제24조), 성능평가 결과서 임의 변경 이용·제출물 외부 유출 금지(제25조).

# 실무 체크리스트

- [ ] 정보보호제품 도입 검수 시 **성능평가기관 지정 유효기간(4년)**과 지정 취소 이력 유무를 확인한다(제16조·제18조).
- [ ] 성능평가 결과서는 **성능평가기관의 사전승인 없이 일부 발췌·인용·배포 불가**(별지 제4호서식 안내문) — 조달문서에 결과서 원문을 첨부할 때 라이선스 조건을 확인한다.
- [ ] 제출물(제품·문서)에 대한 외부 유출·목적 외 사용 금지 의무는 성능평가기관에도 적용되므로(제25조제2항), 신청 시 비밀유지 조항을 계약서에 명시한다.
- [ ] 안전성 검증 대상 제품(전자정부법시행령 제69조제1항제1호)은 세부기준에 **국가정보원 사전 동의**가 필요함을 조달 일정에 반영한다(제8조제4항).
- [ ] 평가 신청 후 **7일 이내 계약 체결**, 종료 후 **10일 이내 결과서 제출**이라는 처리기한을 프로젝트 일정에 반영한다(제9조·제13조).
- [ ] 재검토기한(**2029.12.31.**, 직전 시한 2026.12.31.) 전후 개정 여부를 모니터링한다.
