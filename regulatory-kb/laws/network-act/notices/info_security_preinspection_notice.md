# 요약

「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 제45조의2 및 같은 법 시행령 제36조의2~제36조의5에 따라 **정보보호 사전점검**(이하 "사전점검")의 방법·절차·수수료와 수행기관·수행인력 요건을 정한 고시다(제1조). 사전점검이란 정보통신망 구축 또는 정보통신서비스 제공 이전에 **계획·설계 단계부터** 정보보호를 고려한 조치를 하거나 계획을 마련하는 것을 말한다(제2조). 대상자가 자체 수행하지 않으면 한국인터넷진흥원(KISA) 또는 과기정통부가 지정한 **사전점검 수행기관**으로부터 받으며, 서비스 정의→구조 분석→보호자산 식별→위협/취약점/위험 분석→위협 시나리오 도출→보호대책 도출의 설계 검토 8단계를 거친다.

# 적용 범위

- 대상: **새로이** 정보통신망을 구축하거나 정보통신서비스를 제공하려는 자(제3조). 대상 범위는 하드웨어·소프트웨어·네트워크 등 유·무형 설비 및 시설(제5조).
- 과기정통부는 사전점검을 실시(또는 계약체결)한 사업자에게 **가점 등 우대조치**를 할 수 있다(제4조).
- **재검토기한**: 2017년 1월 1일 기준 매 3년째 12월 31일까지(제27조) — 다음 시한 **2028.12.31.**

# 주요 내용(구조화)

**제2장(제3조~제5조) 실시 시기·대상**: 계획·설계 단계부터 실시(제3조), 우대조치(제4조), 대상 범위(제5조).

**제4장(제6조~제14조) 수행기관**
- **제6조**: 과기정통부가 외부 전문기관을 사전점검 수행기관으로 지정. 지정 필요 시 접수기간·요령을 **20일 이상** 관보·홈페이지에 공고.
- **제7조(지정 요건)**: 시스템·네트워크·DB·SW개발보안·취약점분석평가 등 기술인력 보유, 정보보호컨설팅 수행실적, 별표1의 보호대책(수행구역·설비, 수행인력, 문서·전산자료, 일반 관리적 보호대책) 수립·시행.
- **제9조(지정 신청)**: 별지 제1호서식 신청서 + 기술인력 보유현황(별지 제2호) + 컨설팅 수행실적 명세서(별지 제3호).
- **제10조·제11조(심사·지정)**: 과기정통부가 심사위원회 구성 → 서류심사/현장실사 → 지정서(별지 제4호서식) 교부.
- **제13조(유효기간)**: **3년**. 유지하려면 **만료 3개월 전** 재지정 신청. 인수·합병 등 **법인격 변동 시에도 재지정** 필요.
- **제14조(지정 취소)**: 거짓·부정한 방법 지정 또는 지정요건 미달 시 취소 후 관보 게재 가능. 폐업·반납 시 지정서 첨부해 신청.

**제5장(제15조~제16조) 수행 인력**: 영 제36조의4제3항 별표2 기술인력 자격 기준 보유(제15조), KISA가 서비스구조분석·보호자산식별·위협및취약점분석·위협시나리오작성 등 교육 실시 가능(제16조).

**제6장(제17조~제25조) 사전점검 수행**
- **제17조**: 자체 미수행 시 KISA/수행기관과 **점검기간·참여인력·수수료·범위**를 포함한 실시 계약 체결.
- **제18조**: 사전점검기준은 별표3.
- **제20조(설계 검토, 8단계)**: 서비스 정의 → 서비스 구조 분석 → 보호자산 식별 → 위협 분석 → 취약점 분석 → 위험 분석 → 위협 시나리오 도출 → 보호대책 도출.
- **제21조~제23조**: 보호대책 적용(설계·구현 단계), 구현 현황 점검·시험(모의해킹·침투시험 포함), 결과보고서 작성·제출.
- **제24조(결과 처리)**: 미적용 보호대책은 **보호조치 계획을 수립해 운영과정에 반영**. **심각한 위험 발견 시 보호대책 구현 후에만 운영** 가능.
- **제25조**: KISA원장이 해설서를 마련해 과기정통부장관 승인 후 공표 가능.

**제7장(제26조) 수수료**: 「엔지니어링산업 진흥법」 제31조제2항 대가 기준 또는 「SW사업 대가산정 가이드」 정보보안 컨설팅비를 준용해 별표4로 산정(당사자 합의 시 배제 가능).

# 실무 체크리스트

- [ ] **신규 서비스·망 구축 계획·설계 단계**부터 사전점검을 고려한다(제3조) — 서비스 출시 후 사후 대응이 아니라 **기획 단계 착수**가 핵심.
- [ ] 자체 수행이 아니라면 KISA 또는 지정 수행기관과 점검기간·참여인력·수수료·범위를 명시한 **사전점검 실시 계약**을 먼저 체결한다(제17조).
- [ ] 설계 검토 8단계(서비스 정의~보호대책 도출) 산출물을 프로젝트 문서로 남겨 결과보고서 작성 근거를 확보한다(제20조·제23조).
- [ ] **심각한 위험이 발견된 항목은 보호대책 구현 전 서비스 운영을 개시하지 않는다** — 위반 시 사고 발생 시 귀책 근거가 된다(제24조제2항).
- [ ] 사전점검 실시·계약 체결 사실을 자산화하여 **가점 등 우대조치**(제4조) 신청 시 근거자료로 활용한다.
- [ ] 재검토기한(**2028.12.31.**) 전후 개정 여부를 모니터링한다.
