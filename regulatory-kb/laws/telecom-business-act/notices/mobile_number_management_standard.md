# 요약

「전기통신사업법」 제48조에 따라 비동기방식 이동전화망 구축·식별에 필요한 **이동전화망번호**(국가번호+사업자망번호) 관리 기준을 정한 고시다(제1조·제2조). 이동전화망번호는 ITU가 우리나라에 지정한 국가번호 **450**과, 과기정통부가 이동전화사업자 등에게 부여하는 **5자리 사업자망 번호**로 구성된다. **SKT는 이동통신영역(00~29) 번호를 부여받아 사용하는 이동전화사업자**로서 이 고시의 직접 적용대상이며, 번호 신청·사용목적 준수·회수 사유 발생 시 신고·사업 양도합병 시 번호 승계 절차의 당사자가 된다.

# 주요 내용

## 번호체계 및 부여 (제2장)

- **제4조(번호체계)**: 이동전화망번호 = 국가번호 + 사업자망번호, 총 5자리 십진수.
- **제5조(부여)**: 국가번호는 ITU 지정 **450** 고정. 사업자망 번호는 용도별로 구분해 부여:
  1. **이동통신영역: 00~29** — SKT 등 이동전화사업자가 여기서 부여받음.
  2. 공공영역: 30~39
  3. 5세대 이동통신 특화망 영역: 40~49
  4. 예비대역: 50~99 (번호 부족 시 또는 신규 서비스 출현 시 사용)
  - 연구·시험용/시범서비스용 번호도 일정기간 부여 가능. 여러 사업자 공동사용 부여도 가능.
- **제6조(사용)**: 부여받은 사업자는 **사용목적에 맞게** 사용해야 한다 — SKT도 부여 목적 외 전용 시 회수 사유가 됨에 유의.

## 관리 (제3장)

- **제7조(신청·부여)**: 사용목적·사용계획(5G 특화망은 지리적 범위·타망 접속여부 포함) 첨부해 신청 → **과기정통부는 신청일로부터 1개월 이내 통보**.
- **제8조(회수 등)**: 다음 시 회수 명령 가능 — ①사업 전부/일부 폐지, 등록취소, ②부여받은 자 외의 자 사용, ③번호자원 고갈로 계획 변경, ④번호자원 비효율 관리. 부여받은 사업자는 법 제19조·제20조에 따른 폐지·등록취소, 법 제18조에 따른 양도양수·합병 시 **지체 없이 신고** 의무.
- **제9조(양도양수·합병 시 승계)**: 사업자 지위를 승계한 자가 번호 사용권리·의무를 승계하려면 **과기정통부 승인**(또는 법 제18조제1항 단서 신고대상은 승계 신고) 필요. 승인·신고 시 증빙서류·사용목적·계획 제출. 과기정통부는 특별한 사유 없으면 **종전 번호를 우선 부여**.
- **제10조(사용현황 관리)**: 과기정통부가 확보·부여·사용현황 관리. 국내 할당 번호의 **80% 이상 사용 시 ITU에 국가번호 추가 신청**. 부여·회수 변경내역을 ITU에 통보.
- **제11조(ITU 권고 준용)**: 미규정 사항은 ITU 권고안 따름.
- **제12조(재검토기한)**: 고시 발령일로부터 매 3년.
- **부칙**: 현행 제2021-94호(2021.12.7. 시행)이며 제2019-43호, 제2017-7호(조직개편 일괄개정), 제2017-10호가 개정 이력.

# 실무 체크리스트

- [ ] SKT가 부여받은 이동통신영역(00~29) 번호를 신청 당시 사용목적·계획대로 사용하고 있는지 정기 점검 — 목적 외 사용은 회수 사유(제8조①2호).
- [ ] 5G 특화망 서비스 관련 번호가 필요한 경우 40~49 영역 신청 요건(지리적 범위, 타망 접속여부) 확인.
- [ ] SKT 관련 사업 양도·양수·합병·자회사 조직개편 시 사업자망 번호 승계 절차(제9조) — 승인/신고 구분, 증빙서류 준비를 사전 확인.
- [ ] 신청 후 1개월 내 회신이 지연되는 경우 제7조 처리기한 근거로 확인 요청 가능.
