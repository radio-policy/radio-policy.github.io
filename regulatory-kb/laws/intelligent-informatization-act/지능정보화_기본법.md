# 요약

지능정보사회 구현을 위한 기본법으로, 국가와 지방자치단체의 지능정보화 정책 수립·추진 의무를 규정하고, 종합계획 및 실행계획 수립체계, 한국지능정보사회진흥원 설립, 분야별 추진(공공·지역·민간), 지능정보기술 개발·표준화·인력양성, 초연결지능정보통신기반 구축, 데이터 활용, 역기능 해소 등을 규정한다.

---

# 적용 범위

- **적용 주체**: 국가기관, 지방자치단체, 공공기관, 민간기업, 사업자, 개인(제2조 16호 공공기관 정의 필요)
- **적용 영역**: 지능정보화 정책 수립·시행 전반(행정, 산업, 교육, 의료, 환경, 재난안전, 국방 등)
- **국제협력**: 지능정보기술 개발·활용의 국제협력 추진(제3조 6호)
- **우선순위**: 다른 법률과의 관계에서 본법의 기본원칙을 우선 고려(제5조)

# 주요 내용

## 1. 기본 정의(제2조)

| 용어 | 정의 |
|------|------|
| 정보 | 광·전자적 방식으로 처리되는 부호, 문자, 음성, 음향, 영상 등의 자료·지식 |
| 정보화 | 정보 생산·유통·활용으로 사회활동을 가능하게 하거나 효율화 |
| 정보통신 | 정보 수집·가공·저장·검색·송신·수신 및 관련 기기·기술·서비스 |
| 지능정보기술 | 별도 세부 정의 필요(제2조 4호) |
| 지능정보화 | 정보+지능정보기술 결합으로 사회활동을 효율화·고도화 |
| 지능정보사회 | 지능정보화로 산업·경제·사회·행정 등 모든 분야에서 가치 창출 |
| 지능정보서비스 | 별도 세부 정의 필요(제2조 7호) |
| 초연결지능정보통신망 | 모든 기기·서비스가 언제 어디서나 연결되어 지능정보서비스 이용 가능 |
| 초연결지능정보통신기반 | 초연결망+접속 기기·설비·소프트웨어·데이터 |
| 정보문화 | 지능정보화로 형성되는 행동방식·가치관·규범 |
| 지능정보사회윤리 | 인간중심 지능정보사회 구현을 위한 개인·사회 구성원의 가치판단 기준 |
| 정보격차 | 사회적·경제적·지역적·신체적 여건으로 인한 지능정보서비스 접근 기회의 차이 |
| 지능정보서비스 과의존 | 지나친 이용으로 일상생활에 심각한 지장을 받는 상태 |
| 정보보호 | 정보의 훼손·변조·유출 방지를 위한 관리적·기술적 수단 마련 |

## 2. 기본 원칙(제3조)

- **인간 존엄성**: 자유롭고 개방적 지능정보사회 실현(제1항)
- **경제성장 공유**: 국가경제 발전과 국민생활 질적 향상, 폭넓은 기회 공유(제2항)
- **안전성·개인정보보호**: 역기능 방지, 개인정보·사생활·비밀 보장(제3항)
- **공정한 기회**: 지능정보기술 활용 시 모든 구성원에게 공정한 기회 제공(제4항)
- **민간협력**: 민간의 자유와 창의 존중·지원(제5항)
- **국제협력**: 기술개발의 인류 공동발전 기여(제6항)

## 3. 국가·지방자치단체 책무(제4조)

| 책무 | 내용 |
|------|------|
| 기본 책무 | 기본원칙을 고려하여 지능정보사회 구현 시책 강구(제1항) |
| 규제개선 | 불필요한 규제의 적극적 개선(제2항) |
| 안전성·신뢰성 | 국가기관등의 안전성·신뢰성·공정성 확보 노력(제3항) |
| 불평등 해소 | 지능정보화로 인한 불평등 해소, 노동환경 변화 대응(제4항) |

## 4. 정책 수립·추진 체계

### 4-1. 종합계획(제6조)

- **수립 주기**: 3년 단위
- **수립 기관**: 과학기술정보통신부장관(관계 중앙행정기관, 지방자치단체 의견 수렴)
- **심의**: 정보통신 전략위원회
- **포함 사항**: 기본방향, 분야별 지능정보화, 기술고도화, 산업육성, 규제개선, 정보공동활용·표준화, 법제도 개선, 교육·홍보·인력양성, 정보문화·윤리, 정보보호·정보격차·역기능 해소, 재원조달, 기타 필요사항(제4항 1~11호)
- **이행 점검**: 과학기술정보통신부장관 연 1회 시행 및 전략위원회 보고(제6항)

### 4-2. 실행계획(제7조)

- **수립 주체**: 중앙행정기관장, 지방자치단체장
- **수립 주기**: 매년
- **제출**: 전년도 추진실적·다음년도 계획을 MSIT, 행정안전부에 제출(제2항)
- **지방자치단체 취합**: 행정안전부가 종합하여 MSIT에 제출(제2항)
- **중요사항 변경**: 대통령령 정의 사항은 별도 제출(제3항)
- **점검·분석**: MSIT·행정안전부 공동 점검 후 MSIT가 기획재정부에 의견 제시(제4항)
- **예산편성**: 기획재정부장관이 점검결과를 참작하여 예산 편성(제5항)

### 4-3. 지능정보화책임관(제8조~제9조)

- **임명 의무**: 중앙행정기관장, 지방자치단체장이 임명(제8조 1항)
- **역할**: 기관 지능정보화 시책 수립·시행, 사업 조정(대통령령 정의)
- **협의회 구성**: 중앙행정기관장, 지방자치단체장(광역 이상), MSIT장관, 행정안전부장관, 책임관으로 구성(제9조 1항)
- **협의회 의장**: MSIT장관, 행정안전부장관(제9조 2항)

### 4-4. 정책 조정(제10조)

- **조정 신청**: 중앙행정기관장이나 지방자치단체장이 MSIT장관에게 요청 가능(제1항)
- **조정 결과 통보**: MSIT장관이 해당 기관에 통보(제2항)
- **조정 결과 이행**: 특별한 사유 없으면 반영 의무(제3항)

### 4-5. 지능정보화계획의 반영(제11조)

- **대상**: 사회기반시설사업, 지역개발사업 중 지능정보화 사업 수반 시
- **작성 의무**: 기술활용, 초연결기반 연계, 지능정보서비스 활용 등을 포함한 계획 수립(제1항)
- **예외**: 경미한 사업은 대통령령으로 정하는 기준 해당 시 제외(제1항 단서)
- **검토 사항**: 기존 정보시스템 중복 여부, 연계·공동활용 가능성(제2항)
- **MSIT 검토**: 수립 기관이 MSIT에 제출, MSIT가 검토·의견 제시, 정당한 사유 없으면 이행(제2항)
- **중복투자 방지**: MSIT 협의 가능(제3항)

## 5. 한국지능정보사회진흥원(제12조)

- **설립 주체**: MSIT장관, 행정안전부장관
- **법인 형태**: 법인(민법 재단법인 규정 준용)
- **주요 사업**(제3항):
  1. 계획 수립·시행 전문기술 지원
  2. 기술 보급 시책 지원
  3. 초연결기반 구축·운영 지원
  4. 국가기관등의 망 관리·운영 및 지능정보화 지원
  5. 데이터 관련 시책·시범사업 지원
  6. 정보격차 해소, 과의존 예방·해소 연구
  7. 윤리·정보문화 창달 지원
  8. 지능정보화 사업 평가 지원
  9. 정책 개발 지원(동향분석, 법제 연구)
  10. 교육·홍보·컨설팅, 인력양성, 국제협력
  11. 다른 법령에서 정하거나 위탁한 사업
  12. 국가기관등이 위탁하는 사업
- **재정**: 국가기관등의 출연, 정부의 국유재산 무상 대여(제4항)
- **비용 부담**: 진흥원이 지원받는 국가기관등에 비용 전부 또는 일부 부담 가능(제5항)
- **명칭 보호**: 유사 명칭 사용 금지(제7항)

## 6. 분야별 지능정보화 추진

### 6-1. 부문별 추진계획(제13조)

- 정부가 종합계획에 기초하여 주요 부문별 통일적·효율적 추진 위해 수립 가능
- MSIT장관이 제7조 제4항 의견 제시 시 함께 제시 가능

### 6-2. 공공지능정보화(제14조)

- **대상 분야**: 행정, 보건, 사회복지, 교육, 문화, 환경, 교통, 물류, 과학기술, 재난안전, 치안, 국방, 에너지 등
- **추진 의무**: 국가기관등이 소관 업무 지능정보화 추진
- **방안 마련**: 효율적 추진을 위한 방안 의무(제2항)

### 6-3. 지역지능정보화(제15조)

- **목적**: 주민 삶의 질 향상, 주민 역량강화, 지역 균형발전, 정보격차 해소
- **대상**: 하나 또는 여러 지역·도시의 행정·생활·산업 분야
- **고려사항**: 지역 수요·특성 고려, 관계 기관 의견 수렴(제2항)
- **지원**: 국가기관의 행정·재정·기술 지원(제3항)

### 6-4. 민간 분야 지능정보화(제16조)

- **목적**: 생산성 향상, 부가가치 창출, 국민생활 균등 향상, 국가경쟁력 확보
- **지원 대상**: 기업의 지능정보화, 초연결기반 구축·이용

### 6-5. 민간기관 협력(제17조)

- **민간투자 유치**: 공공·지역 지능정보화 추진 시 민간투자 적극 유치(제1항)
- **협의체 구성**: 대통령령에 따라 민간기관과 협의체 구성·운영 가능(제2항)

### 6-6. 지능정보화 민간 확산(제18조)

- **공공분야 모범**: 공공 지능정보화로 관련 산업 조기 구축, 사회 각 분야 활용 활성화(제1항)
- **정보 유통**: 생성된 지식·정보의 사회 유통·활용 기반 마련(제2항)
