# 요약

본 법은 데이터로부터의 경제적 가치 창출과 데이터산업 발전을 목적으로 한다. 정부의 기본계획 수립(제4조), 국가데이터정책위원회 운영(제6조), 데이터 생산·활용·보호(제2장), 유통·거래 촉진(제4장), 산업기반 조성(제5장)을 통해 체계적으로 데이터산업을 진흥한다. 데이터거래사업자·분석제공사업자 신고제(제16조), 분쟁조정위원회 설치(제34조) 등으로 시장 질서를 확립하고, 중소기업 특별지원(제31조)으로 산업 균형 발전을 도모한다.

# 적용 범위

**대상 데이터**
- 관찰·실험·조사·수집 또는 정보시스템·소프트웨어를 통해 생성되는 광·전자적 처리 가능 자료·정보(제2조제1호)
- 공공데이터, 민간데이터 모두 적용(제2조제2호·3호)

**적용 주체**
- 데이터생산자: 데이터 생성·가공·제작 경제활동자(제2조제4호)
- 데이터사업자: 데이터산업 영위자(제2조제6호)
- 데이터거래사업자: 데이터 판매 또는 중개·알선을 업으로 하는 자(제2조제7호)
- 데이터분석제공사업자: 수집·결합·가공·분석 정보 제공 업체(제2조제8호)

**제외 사항**
- 개인정보: 「개인정보보호법」 적용(제7조제2항)
- 저작권: 「저작권법」 적용(제7조제2항, 제13조제2항)
- 공공데이터 제공거부·제공중단 분쟁: 「공공데이터의 제공 및 이용 활성화에 관한 법률」 적용(제34조제1항)

# 주요 내용

## 1. 정책 수립 및 추진 체계

### 기본계획(제4조)
- **수립 주기**: 3년마다
- **수립 주체**: 정부(관계 중앙행정기관과 협의)
- **심의기구**: 국가데이터정책위원회
- **필수 포함 사항**:
  - 데이터 생산·거래·활용 촉진 시책 기본 방향
  - 데이터 생산 및 보호
  - 데이터 거래 촉진
  - 데이터 활용 활성화
  - 전문인력 양성
  - 산업기반 조성
  - 중소기업 특별지원(제31조 반영)
  - 국제협력 지원

### 시행계획(제5조)
- **수립 주체**: 과학기술정보통신부장관
- **공공데이터 협의**: 행정안전부장관과 협의(제5조제1항)
- **심의**: 국가데이터정책위원회
- **연차별 추진**

### 국가데이터정책위원회(제6조)
- **위원장**: 국무총리
- **구성**: 위원장 1명 + 30명 이내 위원
- **위원 구성**:
  - 14부처 장관 및 위원회 위원장(제6조제3항제1호)
  - 데이터산업 전문가 위촉(2년, 1회 연임)
- **간사위원**: 과학기술정보통신부·행정안전부 장관
- **사무국**: 과학기술정보통신부 내 설치 가능

## 2. 데이터 생산·활용·보호

### 데이터 생산 활성화(제9조)
- 정부의 환경 조성 책무
- 데이터생산자에 대한 재정·기술 지원
- 공동활용을 통한 개발·연구 촉진

### 데이터 결합 촉진(제10조)
- 과학기술정보통신부장관·행정안전부장관의 책무
- 산업 간 교류, 융합기반 구축
- 공공·민간데이터 결합 촉진
- 지원 대상:
  - 연계 교육 프로그램 개발
  - 전문인력 교류
  - 결합 데이터 거래·활용
  - 자금 지원

### 데이터안심구역(제11조)
- **지정 주체**: 과학기술정보통신부장관·관계 중앙행정기관 장
- **기능**: 안전한 데이터 분석·활용 구역 제공
- **지원**: 미개방데이터, 분석 시스템·도구 제공
- **데이터 제공**: 정부·지자체·공공기관·민간법인에 요청 가능
- **보안대책**: 기술적·물리적·관리적 보안 수립·시행(제11조제5항)

### 데이터자산 보호(제12조)
- **정의**: 인적·물적 상당 투자·노력으로 생성된 경제적 가치 데이터
- **보호 대상 행위**:
  - 공정한 거래 관행·경쟁질서 위반 방법의 무단 취득·사용·공개
  - 정당한 권한 없는 기술적 보호조치 회피·제거·변경
- **법적 근거**: 「부정경쟁방지 및 영업비밀보호에 관한 법률」 적용(제12조제3항)

### 정보분석 지원(제13조)
- 정부의 데이터 기반 정보분석 활성화 지원
- 저작물등의 저작권 보호 준수(제13조제2항)

## 3. 데이터 이용·거래 촉진

### 가치평가(제14조)
- **평가기법 및 체계**: 과학기술정보통신부장관이 수립·공표
- **평가기관 지정**: 전문 가치평가기관 지정 가능
- **신청 절차**: 신청자가 평가기관에 신청
- **통보 의무**: 평가기관은 지체 없이 결과 통보
- **정보 보고**: 당해 연도 평가정보를 다음 연도 1월 말까지 보고(단, 경영·영업상 비밀 제외)
- **협의 대상**: 평가 대상·범위·수수료

### 데이터 이동 촉진(제15조)
- 정보처리장치 처리 가능 형태로의 원활한 이동
- 제도적 기반 구축

### 데이터사업자 신고(제16조)
- **신고 대상**:
  - 데이터거래사업자
  - 데이터분석제공사업자
- **신고 주체**: 과학기술정보통신부장관
- **변경 시 재신고**
- **지원**: 재정·기술 지원 가능(제16조제2항)
- **기준·절차**: 과학기술정보통신부령으로 규정

### 공정한 유통환경 조성(제17조)
- **대기업·중소기업 공정 경쟁 환경 조성**
- **불공정 행위 금지**(제17조제2항):
  - 지식재산권 일방적 양도 요구
  - 부당한 이득 취득
  - 불공정 계약 강요
- **위반 시 조치**: 관계 기관에 필요한 조치 요청 가능
- **거래 시장 활성화 사업**:
  - 시장 현황 분석·평가
  - 거래사업자 협의체 운영
  - 표준계약서 실태조사
  - 공정 경쟁 환경 조성 사업

### 데이터 유통·거래 체계(제18조)
- **데이터유통시스템**: 과학기술정보통신부장관이 구축·운영
- **기반 조성 지원**: 필요한 지원 가능

### 데이터 플랫폼 지원(제19조)
- 수집·가공·분석·유통·서비스 제공 플랫폼 지원 사업

### 데이터 품질관리(제20조)
- **협의**: 행정안전부장관과 협의
- **인증기관 지정**: 품질인증 실시 기관
- **품질기준**: 대통령령으로 규정
- **인증 표시 미사용 벌칙**: 3천만원 이하 과태료(제48조)

### 표준계약서(제21조)
- **마련**: 공정거래위원회와 협의
- **권고**: 데이터사업자에게 사용 권고
- **의견 수렴**: 사업자단체·전문가 의견 청취

### 자료 제출 요청(제22조)
- 대상: 데이터거래사업자·분석제공사업자
- 요청 항목: 기술인력, 사업 수행실적 등

### 데이터거래사 양성(제23조)
- **등록 자격**: 대통령령에서 정한 경력·자격 기준
- **교육**: 대통령령에서 정한 교육 이수
- **업무**: 전문 상담·자문·지도, 중개·알선
- **등록 취소**:
  - 거짓·부정한 방법 등록 (필수 취소)
  - 거짓·부정한 업무 수행
  - 다른 사람의 등록 명의 사용

## 4. 산업기반 조성

### 창업 및 기업 지원(제24조)
- **지원 내용**:
  - 데이터 기반 상품·서비스 개발, 테스트베드 운영
  - 기술역량 강화 교육 프로그램
  - 투자생태계 활성화
  - 상담 지원
  - 우수 아이디어 발굴·사업화 지원
- **전문기업 육성**: 데이터 기술 보유 기업 육성

### 전문인력 양성(제25조)
- **수립 기관**: 과학기술정보통신부장관·행정안전부장관
- **시책 내용**:
  - 양성 정책 기본방향·활용 방안
  - 교육·훈련 프로그램 개발
  - 학계·산업계·공공기관 협력
  - 고용창출·연계 지원
  - 직무표준 마련, 신직종 정착 지원
- **양성기관 지정**: 대학·연구기관·전문기관 지정
- **훈련비용 지원**: 「국민 평생 직업능력 개발법」에 따른 지원

### 기술개발 촉진 및 시범사업(제26조)
- **주체**: 과학기술정보통신부장관
- **시책 내용**:
  - 기술 발전목표·산업 적용
  - 투자 재원 확보
  - 연구개발사업 추진, 협동연구·학제간 연구 촉진
  - 연구기반 확충
  - 국제협력 촉진
  - 연구성과 확산·기술이전

### 실태조사(제27조)
- **주기**: 매년
- **내용**: 산업 기반, 거래 현황·실태
- **결과 공표**: 의무
- **자료 요청**: 관계 기관·지자체·공공기관에 요청 가능
- **위탁**: 전문기관에 위탁 가능

### 표준화 추진(제28조)
- **협의**: 행정안전부장관과 협의
- **표준 대상**:
  - 데이터 저장 형태·이전 방식
  - 분류 체계
  - 결합·거래·활용 필요 사항
- **한국산업표준 준용**: 이미 제정된 KS 기준 따름
- **사업**: 조사·연구·개발, 국제표준화기구 협력

### 국제협력(제29조)
- 국제동향 파악
- 외국정부·국제기구·외국 기업·단체와의 협력 촉진

### 세제지원 및 보조금(제30조)
- **세제감면**: 국세·지방세 감면 가능
- **보조금·장기대부**: 대통령령에서 정한 경우 지급 가능
-
