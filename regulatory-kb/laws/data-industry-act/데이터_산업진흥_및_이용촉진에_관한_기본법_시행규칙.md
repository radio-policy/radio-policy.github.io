# 요약

본 규칙은 「데이터 산업진흥 및 이용촉진에 관한 기본법」(이하 '법') 및 같은 법 시행령에서 위임된 사항의 세부 시행을 규정한다. 데이터 가치평가기관·품질인증기관 지정, 데이터거래사 등록, 데이터사업자 신고 등 주요 행정절차의 신청서 양식 및 처리기준을 제시하고, 데이터 품질인증 표시기준(도형·색상·방법)을 명시한다.

# 적용 범위

- **지정 대상**: 데이터 가치평가기관, 데이터 품질인증기관, 데이터 전문인력 양성기관
- **등록 대상**: 데이터거래사
- **신고 대상**: 데이터거래사업자, 데이터분석제공사업자
- **신청인**: 법인, 개인, 단체 등 관련 사업 운영 주체

# 주요 내용

## 1. 데이터 가치평가기관 (제2조~제3조)

### 지정 신청 (제2조)
- **신청서 서식**: 별지 제1호서식 통일 사용 (접수번호, 접수일, 처리기간 60일 명기)
- **필수 제출서류**:
  - 정관
  - 사업계획서
  - 시행령 제14조제1항 제1호·제2호·제4호 기준 충족 증명서류
  - 데이터 가치평가 모델·기법의 체계 및 설명서
  - 법인 등기사항증명서
- **지정서**: 별지 제2호서식으로 발급, 과학기술정보통신부장관 인장 필수

### 가치평가 신청 (제3조)
- **신청서 서식**: 별지 제3호서식 통일 사용
- **신청인 구분**: 법인/개인별 작성 방법 상이
- **필수 첨부**: 가치평가 대상 데이터 관련 자료

## 2. 데이터사업자 신고 (제4조)

### 신고 절차
- **신고서 서식**: 별지 제4호서식 (신규·변경 구분)
- **신고 분야**: 데이터거래사업자 / 데이터분석제공사업자 / 병행사업자
- **제출처**: 과학기술정보통신부장관 (전자문서 포함)
- **처리기간**: 7일

### 행정정보 공동이용 (제4조제2항)
- 신고인이 동의하면 「전자정부법」 제36조제1항에 따른 공동이용으로 사업자등록증 확인
- 동의 거부 시 신고인이 직접 사업자등록증 첨부

### 신고 확인서 (제4조제3항)
- **발급 서식**: 별지 제5호서식
- **기재사항**: 신고번호, 발급번호, 회사명, 대표자, 소재지, 신고일, 사업분야

### 변경 신고
- 신고 사항 변경 시 변경 신고서 재제출 의무
- 별지 제4호서식 사용

## 3. 데이터 품질인증기관 (제4조의2~제4조의3)

### 인증기관 지정 (제4조의2)
- **신청서 서식**: 별지 제5호의2서식 (처리기간 60일)
- **필수 제출서류**:
  - 정관
  - 데이터 품질인증 사업계획서
  - 시행령 제20조의3제1항 각 호 요건 충족 증명서류
  - 법인 등기사항증명서
- **지정서**: 별지 제5호의3서식으로 발급

### 품질인증 신청 (제4조의3)
- **신청서 서식**: 별지 제5호의4서식
- **인증서 서식**: 별지 제5호의5서식
- **표시기준**: 별표 규정 준수

### 품질인증 표시기준 (별표)

#### 표시도안
- **선택 사항**: A 또는 B 도형 중 용도에 맞게 선택 가능
- **구성**: 도형(테두리, 화살표) + 문구

#### 색상 규정
| 구분 | 색정보 |
|------|--------|
| 바깥 테두리 | 옅은 회색 (Cyan 1, Magenta 1, Key 17) |
| 위 둥근 화살표 | 옅은 하늘색→짙은 파란색 계조 (Cyan 74~96, Magenta 19~57, Key 5) |
| 아래 둥근 화살표 | 남색 (Cyan 69, Magenta 67, Key 43) |
| 안쪽 테두리 | 회색→옅은 회색 계조 (Magenta 1, Key 28~11) |
| 도형 내 글자 | 남색 (Cyan 69, Magenta 67, Key 43) |
| 문구 | 회색 (Cyan 69, Magenta 67, Key 43) |

#### 표시 방법
- 크기: 용도에 따라 같은 배율로 조정 가능
- 인쇄·새김 등 수단 사용
- 색상 임의 변경 금지
- 영문과 병기 시 상하 조합 배치

## 4. 데이터거래사 등록 (제5조)

### 등록 신청 (제5조)
- **신청서 서식**: 별지 제6호서식
- **등록증 서식**: 별지 제7호서식

## 5. 데이터 전문인력 양성기관 (제6조)

### 지정 신청 (제6조)
- **신청서 서식**: 별지 제8호서식 (처리기간 60일)
- **지정서 서식**: 별지 제9호서식

# 실무 체크리스트

## 데이터 가치평가기관 지정 신청자
- [ ] 정관 제출 확인
- [ ] 사업계획서 작성
- [ ] 시행령 제14조제1항 기준(자본금, 인력, 장비, 운영능력) 충족 서류 준비
- [ ] 가치평가 모델·기법 설명서 작성
- [ ] 법인 등기사항증명서 첨부
- [ ] 별지 제1호서식으로 신청 (60일 처리)

## 데이터사업자 신고자
- [ ] 신규/변경 선택
- [ ] 신고 분야 해당 항목 선택 (√ 표시)
- [ ] 회사명·대표자·사업자등록번호 정확 입력
- [ ] 행정정보 공동이용 동의 여부 결정
- [ ] 동의 미표시 시 사업자등록증 사본 첨부
- [ ] 담당자 정보 기재
- [ ] 별지 제4호서식으로 신고 (7일 처리)
- [ ] 변경 시 변경신고 재제출

## 데이터 품질인증기관 지정 신청자
- [ ] 정관 제출 확인
- [ ] 데이터 품질인증 사업계획서 작성
- [ ] 시행령 제20조의3제1항 요건 충족 서류 준비 (시설, 인력, 능력)
- [ ] 법인 등기사항증명서 첨부
- [ ] 별지 제5호의2서식으로 신청 (60일 처리)

## 데이터 품질인증 표시자
- [ ] 도형 A/B 중 선택 결정
- [ ] 색상 CMYK 수치 정확히 적용 (변경 금지)
- [ ] 크기 조정 시 배율 일정 유지
- [ ] 인쇄·새김 품질 확인
- [ ] 영문 병기 시 상하 배치 확인
- [ ] 별표 기준 준수 검증

## 데이터거래사 등록자
- [ ] 별지 제6호서식으로 신청서 작성
- [ ] 등록증 발급 시 별지 제7호서식 확인
