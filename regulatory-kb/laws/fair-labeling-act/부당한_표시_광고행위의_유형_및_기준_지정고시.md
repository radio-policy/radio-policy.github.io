# 요약

본 고시는 「표시·광고의 공정화에 관한 법률」 제3조에 규정된 부당한 표시·광고행위의 판단기준을 명확히 하기 위해 소비자오인성과 공정거래저해성의 2가지 핵심 요소를 제시한다. 소비자오인성은 보통의 주의력을 가진 일반소비자가 받게 되는 전체적·궁극적 인상을 기준으로 판단하며, 공정거래저해성은 표시·광고가 소비자의 합리적인 구매결정을 방해할 우려가 있는지를 기준으로 한다. 고시는 가격, 원재료, 품질, 규격, 원산지, 보증, 추천 등 14개 영역별 부당광고 유형과 구체적 예시를 제공하여 사업자의 준수를 지원한다.

---

# 적용 범위

- **적용대상**: 상품 또는 용역의 표시·광고 행위를 하는 모든 사업자, 사업자단체
- **적용법령**: 「표시·광고의 공정화에 관한 법률」 제3조제1항 및 동법 시행령 제3조제1항~제4항
- **규율범위**: 거짓·과장의 표시·광고, 기만적 표시·광고, 부당비교 표시·광고, 비방적 표시·광고
- **예시적 성격**: 고시에 열거되지 않은 사항도 부당광고에 해당할 수 있으며, 열거된 사항도 소비자오인성·공정거래저해성이 없으면 위반이 아닐 수 있음

# 주요 내용(구조화)

## 1. 부당 표시·광고 판단의 기본 틀

### 1.1 소비자오인성(消費者誤認性) 판단기준

**기본원칙**
- 보통의 주의력을 가진 일반소비자가 해당 표시·광고를 받아들이는 **전체적·궁극적 인상**을 객관적으로 판단 (법 제3조제1항)

**판단의 세부 요소**
1. 판단주체: 일반소비자 기준 (전문가·저주의력자 제외)
   - 특정 집단 대상 광고(의사, 환자, 어린이)는 해당 집단의 보통 주의력 기준으로 판단 가능
2. 판단대상: 사업자의 의도가 아닌 소비자의 **실제 인상**
3. 판단범위: 문리적 의미뿐 아니라 간접적·전체적 표현 포함
4. 입증: 오인 경향·가능성만으로 충분 (실제 기만 입증 불요)
5. 예외: 누가 보아도 명백한 허위, 사회적으로 용인되는 광고적 표현(예: "최적의 전원요지"), 주관적 판단(맛, 느낌) 등은 소비자오인성 부정

### 1.2 공정거래저해성(公正去來阻害性) 판단기준

**기본원칙**
- 광고로 인해 소비자의 **합리적인 구매결정을 방해**함으로써 관련시장의 공정한 거래질서를 저해할 우려 여부 판단

**판단의 세부 요소**
1. 기준: 합리적 구매결정 방해의 우려
2. 거짓·과장된 법 제2조 제1호 사항(상품 규격, 품질, 가격 등) 광고는 일반적으로 공정거래저해성 인정 가능성 높음
3. 은폐·축소·누락의 중요성:
   - 제품의 본질적 기능·성능·효능·품질 관련
   - 건강·안전 관련
   - 가격, 철회권 관련
   - 광고주와 추천자 간 경제적 이해관계 관련
   - 소비자 손해 발생 가능성 존재
   
   위 5가지 중 하나에 해당하면 일반적으로 공정거래저해성 인정 가능성 높음
4. 예외: 공익캠페인, 상품 구매 결정과 무관한 광고 등은 공정거래저해성 부정
5. 입증: 방해 경향·가능성만으로 충분 (실제 방해 입증 불요)

## 2. 영역별 부당광고 유형

### 2.1 사업자 자신에 관한 표시·광고
- 규모, 연혁, 생산시설, 수상경력, 사업계획, 사업실적, 기술제휴 등을 사실과 다르게 또는 과장·모호하게 표시·광고
- **예시**: "세계최대 규모", 미확정 사실을 "확실한 사실"처럼 표시(상장 시기), 미진척 사업을 구체적 조감도로 "착공기일·준공기간 확정"처럼 표시

### 2.2 가격에 관한 표시·광고

**2.2.1 "가격" 용어 사용**
- 소매업자(직매장 포함)만 실제 판매가격을 표시·광고 의무
- 제조업자·유통업자·수입업자는 희망소매가격 등 표시·광고 가능 (권장·참고 목적)
- 희망소매가격이 일정 거래지역의 상당수 소매업자 판매가격을 현저히 초과하면 부당광고

**2.2.2 가격 비교**
- 거짓의 종전거래가격 비교 (예: "1,500원에서 750원으로 인하" 시 타상품과 비교는 부당)
- 거짓의 시가 비교 (예: "시가 1,000원→당첨판매가 700원" 중 시가가 거짓)
- 거짓의 희망소매가격 비교 (실제 희망소매가격 비교 시 그 사실 명시 필수)
- 거짓의 타사 가격 비교

**2.2.3 중고품·하자품·구형 상품 가격**
- 신품 가격을 비교기준으로 하여 중고품 등이 저가인 것처럼 표시하는 행위 부당
- 육안으로 식별 가능한 경우는 제외

**2.2.4 할인판매 등**
- 할인율을 거짓 근거로 산출하여 표시
- 실제 할인가보다 낮은 가격 표시
- 조악상품을 정상상품인 것처럼 표시
- 가격인하폭 과장 (20일 이상 거래한 적 없는 가격을 종전가격으로 표시)
- 일부 상품·매장의 할인을 대부분인 것처럼 표시
- 일부만 높은 할인율을 대부분인 것처럼 과장
- 부족한 재고를 충분한 것처럼 과장
- 할인 종료 후 현수막을 제거하지 않아 계속되는 것처럼 표시
- 염가판매·점포정리판매 시 할인인 것처럼 오인시킬 우려의 종전거래가격 기준 할인율 표시 (비교가격 표시 시 기준 명시 필수)
- 가격인하판매 시 비교가격 기준·인하시점 미명시
- 실제 변동 없이 한정 기간·한정 수량 표시
- 할인특매 아닌데 그것처럼 표시

**2.2.5 할부판매가격**
- 실제 할부가격 미명시 (현금가처럼 표시)
- 할부금리 미표시 (할부액만 표시)

**용어 정의**
- 종전거래가격: 최근 약 20일간 판매한 가격 (변동 시 최저가)
- 시가: 동일 거래지역 상당수 사업자의 판매가격
- 희망소매가격: 제조업자 등이 최근에 붙인 미리 공표되고 거래에 참고되는 가격

### 2.3 원재료·성분에 관한 표시·광고
- 실제 미사용 재료·성분을 포함된 것처럼 표시
- 실제 사용량보다 많이 포함된 것처럼 과장
- 수입원재료 미사용을 사용한 것처럼 표시
- 수입 부재료를 완제품 수입인 것처럼 표시
- 부사용 원재료·성분을 주된 성분인 것처럼 표시
- **예시**: 50% 실크+50% 레이온을 "100% 실크" 또는 "실크"라 표시

### 2.4 품질·성능·효능 등에 관한 표시·광고
- 품질·성능이 미충족을 충족하는 것처럼 표시
- 성능 판단기준 미명시 (막연한 성능 표시)
- 부분 품질·성능을 전체인 것처럼 과장
- 객관적 확인 불가·미확인된 성능·효능을 확실한 것처럼 표시
- 특허 등록 자체만으로 성능·효능·안전성 우수성 광고
- **예시**: 연비 표시 시 운행 조건(시내/고속도로) 미명시, 미인정 의약품 효능 표시, 제한적 실험 조건 강조, 차량 배출가스 기준 미충족 사실 은폐

### 2.5 규격·용량·수량 등에 관한 표시·광고
- 기준규격 미충족을 충족하는 것처럼 표시
- 실제와 다른 용량·수량 표시
- 외형 크기를 내형인 것처럼 표시
- **예시**: KS규격 미해당을 규격이라 표시, 냉장고 외형 300ℓ를 내용적인 것처럼 표시, 실내용적 미달

### 2.6 제조일자·유효기간 등에 관한 표시·광고
- 제조일자 표시 없이 "제조일자로부터 ○○일간 유효"만 표시
- 제조일자·유효기간을 소비자가 식별하기 곤란하게 표시
- 소모·마모를 영구 또는 장기간 존속하는 것처럼 표시

### 2.7 제조방법에 관한 표시·광고
- 반자동을 자동화 생산으로 표시
- 단순 기술연수를 기술제휴라 표시
- 기계 제조를 손제조인 것처럼 표시

### 2.8 특징에 관한 표시·광고
- 화학반응 상품을 "천연제품"이라 표시
- "반자동"을 "자동" 또는 "전자동"이라 표시
- 전년도 재고를 "개정신판", "완전신판"이라 표시

### 2.9 원산지·제조자에 관한 표시·광고

**국산품의 외국문자 표시**
- 국내 제조를 외국문자·외국어로만 표시 (제외: 실제 원산지가 외국산)

**수입품의 국산 위장**
- 수입품을 국산으로 거짓 표시
- 실제 원산지 미표시 또는 식별 곤란하게 표시
- 상표 혼동 우려 표시

**기술제휴 제품**
- 외국 상표·제조사명만 표시하고 국내 생산 사실 미표시 또는 식별 곤란

**수입 부재료·국내 조립**
- 일부 수입 재료로 국내 제조·조립되었음에도 외국 생산인 것처럼 표시
- 제조자 미표시

**상표 혼동**
- 타사 상표·상호로 자사 상품 표시
- 타사 상표와 유사 상표로 혼동 유발

**특정지역 산지 위장**
- 유명산지 생산인 것처럼
