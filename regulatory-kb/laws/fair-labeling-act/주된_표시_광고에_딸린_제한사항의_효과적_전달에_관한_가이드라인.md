# 요약

본 가이드라인은 『표시·광고의 공정화에 관한 법률』 제3조 위반을 방지하기 위해, 주된 표시·광고의 의미·적용범위를 제한하는 종속된 주장(제한사항)을 소비자에게 효과적으로 전달하는 방법을 제시한다. 소비자는 광고를 개략적으로만 확인하는 특성을 고려하여, 제한사항이 단순히 형식적으로 기재되는 것으로는 부족하며, 두드러짐·근접성·명확성의 세 가지 요소를 충족하여 전달되어야 함을 명시한다.

# 적용 범위

- 모든 사업자의 상품·용역에 관한 표시·광고(신문, TV, 인터넷 홈페이지 등 모든 매체 포함)
- 주된 표시·광고에 제한사항이 부수되는 경우
- 『표시·광고의 공정화에 관한 법률』 제3조(부당한 표시·광고 행위의 금지) 적용 대상

# 주요 내용

## 1. 목적 및 법적 배경
- 소비자행동과학의 발전: 일반 소비자는 광고의 표제·전반적 맥락·이미지·음향 등을 통해 종합적 인상을 형성함
- 대법원 판례: 소비자 오인성 판단은 표시·광고의 종합적 인상을 기준으로 객관적으로 판단
- 기존 관행의 문제점: 제한사항을 맨 하단 작은 글씨 또는 별도 홈페이지로 형식적 전달 → 소비자 오인성 제거에 부족

## 2. 용어 정의

**주된 표시·광고**: 제한사항에 의해 의미·적용범위 등이 제한되는 표시·광고

**제한사항**: 사업자의 주장 내용·적용범위를 제한하기 위해 각주·별표·괄호 등 형태를 불문하고 주된 표시·광고에 덧붙여 제시되는 종속된 주장

## 3. 일반원칙

| 원칙 | 내용 |
|------|------|
| 1. 효과적 전달 | 제한사항의 내용이 명확하고 소비자 눈에 잘 띄어야 함 |
| 2. 판단기준 | 두드러짐·근접성·명확성·구체성·평이성을 고려한 종합적 인상 기준 판단 |
| 3. 다매체 원칙 | 신문·TV·인터넷 등 모든 매체에서 각각 효과적으로 전달되어야 함 |
| 4. 한계 | 제한사항은 거짓 주장을 치유할 수 없으며, 주된 표시·광고가 거짓이면 그 자체가 수정되어야 함 |

## 4. 제한사항 효과적 전달의 세부 요소

### 가. 두드러짐(Prominence)

**요구사항**:
- 소비자가 쉽게 읽을 수 있을 정도의 충분한 크기
- 배경과 뚜렷히 구분되는 색상 처리
- 광고의 다른 내용에 함몰되지 않도록 노출 시간·비중 확보

**부적절 사례**:
- 신문광고에서 제한사항 배경을 어둡게 처리하여 구분 불가능
- "한 달 만에 7kg 감량" 광고 후 "3개월 복용 시"를 소비자가 인식 불가능한 작은 글씨로 표기
- TV홈쇼핑에서 LCD모니터 제조사 정보를 총 방송 100분 중 40초(1회 5초×8회)의 하단자막으로만 표시
- 보험광고 가입조건·갱신조건을 약 1초 정도의 지나치게 작은 글씨로 화면 하단 표시

### 나. 주된 표시·광고와의 근접성(Proximity)

**요구사항**:
- 제한사항을 주된 표시·광고 근처에 배치
- 소비자가 쉽게 읽을 수 있는 위치
- 주된 주장과 제한사항을 통일된 속성으로 인식 가능하도록 함

**부적절 사례**:
- 신문 전면광고에서 제한사항을 왼쪽 하단 코너의 작은 글씨로 기재
- '썩는 비닐' 표시와 제한사항('상온 습도 40% 이상 토양 매립 시')을 포장 양면에 분리 기재
- "자격증 취득 시 취업보장" 광고와 "6개월 무급 인턴쉽 필수" 조건을 상이한 웹페이지에 게시

### 다. 표현의 명확성·구체성 및 평이성(Clarity, Specificity, Plainness)

**요구사항**:
- 제한사항의 의미가 명확하고 구체적
- 소비자 이해 용어와 문장 사용
- 추가 설명 없이 난해한 법률용어·기술용어 사용 금지

**부적절 사례**:
- 결혼정보업체의 "업계 1위" 광고에서 제한사항으로 "'랭키닷컴' 기준"만 표기, 의미 설명 없음
- "개인정보 제3자 제공"을 "자세한 사항은 응모권이나 홈페이지 참고"로만 표기(추상적)
- "공기청정기 99.9% 유해물질 제거"에 "실사용 조건에 따라 차이가 있을 수 있음"만 기재(관행적 회피)
- "미세먼지 99.95% 제거"를 "EN1822 실험실 검사 결과"로만 표기, 기준 설명 없음

## 5. 적용 원칙

- 일률적 세부기준 불가능 → 사업자는 광고 내용·매체·제반사항을 종합 고려하여 최적 전달방안 모색
- 모든 매체에서 각각 효과적 전달 필수(신문, TV, 인터넷 등 별도 평가)
- 제한사항 전달 부족 시 주된 표시·광고의 종합적 인상 변경 불가 → 부당표시광고 해당

# 실무 체크리스트

## 제한사항 설정 단계
- [ ] 주된 표시·광고에 제한사항이 필요한지 검토
- [ ] 제한사항이 거짓 주장 치유용인지 확인(거짓 주장은 제한사항이 아닌 주장 자체 수정)
- [ ] 제한사항의 내용이 주된 광고의 의미·범위를 실질적으로 제한하는지 검증

## 두드러짐(Prominence) 검증
- [ ] 텍스트 크기가 소비자가 명확히 읽을 수 있는 수준인가
- [ ] 배경색·텍스트색의 명도 차이가 충분하여 구분 가능한가
- [ ] 멀티미디어 광고에서 노출 시간(초 단위)·화면상 비중(%)이 적절한가
- [ ] 광고의 주요 메시지와 비교하여 상대적 두드러짐이 부족하지 않은가

## 근접성(Proximity) 검증
- [ ] 제한사항이 주된 표시·광고 근처에 물리적으로 배치되어 있는가
- [ ] 소비자가 주된 주장을 읽을 때 제한사항을 자연스럽게 인식할 위치인가
- [ ] 다중 페이지·화면의 경우 주된 주장이 있는 페이지/화면에 제한사항도 함께 제시되었는가
- [ ] 온라인의 경우 추가 클릭·스크롤이 필요하지 않은가

## 명확성·구체성·평이성(Clarity) 검증
- [ ] 제한사항의 의미가 모호하거나 추상적이지 않은가
- [ ] 기술용어·법률용어를 사용할 경우 별도 설명이 포함되었는가
- [ ] 일반 소비자 수준에서 추가 자료 검색 없이 이해 가능한가
- [ ] 수치·수식·조건이 구체적으로 명시되었는가(관행적 "~수 있음" 회피)

## 다매체 일관성 검증
- [ ] 신문·TV·라디오·인터넷 등 각 매체별로 동일한 수준의 제한사항이 전달되는가
- [ ] 온라인 광고(배너·SNS·동영상)와 오프라인 광고의 제한사항이 일관되는가
- [ ] 매체 특성상 제한사항 표현이 다를 경우 효과성 수준이 동등한가

## 최종 심사
- [ ] 제한사항이 실제로 소비자 오인성을 제거할 수 있는가
- [ ] 일반인이 광고를 "대략적으로만" 봐도 제한사항을 인식할 수 있는가
- [ ] 거짓 주장 은폐 목적의 제한사항이 아닌가
