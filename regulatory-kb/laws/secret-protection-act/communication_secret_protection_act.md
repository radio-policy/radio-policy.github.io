# 요약

우편물 검열·전기통신 감청(통신제한조치)과 통신사실확인자료(통화일시·상대방 번호·발신기지국 위치추적자료 등) 제공은 원칙적으로 금지되며, 법원 허가 등 엄격한 절차를 거친 경우에만 예외적으로 허용된다. SKT는 **"전기통신사업자"**로서 ①수사기관의 통신사실확인자료 제공 요청에 협조할 의무(제13조·제15조의2), ②통신제한조치 집행 위탁을 받을 수 있는 지위(제9조), ③자료 제공 현황을 반기별로 과학기술정보통신부에 보고하고 대장을 7년간 비치할 의무(제13조⑦)를 진다. 협조 거부·기재사항 누락·비밀누설은 형사처벌(제16조·제17조) 대상이다.

# 통신사실확인자료 제공 — SKT 실무 핵심

- **제2조제11호(정의)**: 통신사실확인자료 = 가입자 전기통신일시, 개시·종료시간, **발·착신 통신번호 등 상대방 가입자번호**, 사용도수, 인터넷 로그기록자료, **발신기지국의 위치추적자료**, 접속지 추적자료. 위치추적자료·로그기록은 실시간 추적자료로 별도 요건 적용(제13조②).
- **제13조(범죄수사를 위한 통신사실 확인자료제공의 절차)**: 검사·사법경찰관이 SKT 등 전기통신사업자에게 자료 열람·제출을 요청. 원칙은 관할 지방법원의 **허가서**가 필요하며, 실시간 추적자료·특정 기지국 자료(②)는 다른 방법으로 수사가 어려운 경우로 제한. 긴급한 경우 선제공 후 사후허가(③단서) 가능하나 **허가를 못 받으면 즉시 폐기**(④). SKT는 제공사실을 대장에 기록하고 **자료제공현황을 연 2회 과학기술정보통신부장관에게 보고**, 관련자료를 제공일부터 **7년간 비치**(⑦).
- **제13조의2**: 법원도 재판상 필요시 SKT에 통신사실확인자료제공을 직접 요청 가능.
- **제13조의3(통지의무)**: 수사기관이 SKT로부터 자료제공을 받은 사건은 처분 후 30일 이내 당사자(가입자)에게 서면 통지 — SKT가 직접 통지하는 것은 아니나, 고객 문의 시 이 통지 절차를 안내할 근거.
- **제13조의4**: 국가안보 목적(정보수사기관)의 통신사실확인자료제공 요청 — 제7~9조 절차 준용.

# 통신제한조치(감청) — SKT 협조 의무

- **제9조(집행)**: 검사 등은 SKT 등 "통신기관등"에 통신제한조치 집행을 **위탁**하거나 협조를 요청할 수 있음. SKT는 허가서 사본을 확인 후 집행에 협조하되, **대상자 전화번호가 허가서와 불일치하면 집행 거부 가능**, 비밀번호는 어떤 경우에도 누설 금지(④).
- **제8조(긴급통신제한조치)**: 법원 허가 없이 착수 가능하나 **36시간 내 미승인 시 즉시 중지·자료 폐기** — SKT가 위탁 집행 중인 경우 통지받는 즉시 대응.
- **제12조(사용제한)**: 감청으로 취득한 내용은 해당 범죄 수사·소추, 손해배상소송 등 법정 목적 외 사용 금지.
- **제15조의2(전기통신사업자의 협조의무)**: SKT는 수사기관의 통신제한조치·통신사실확인자료제공 요청에 **협조하여야 한다**(강행규정). 협조 방법·보관기간은 시행령 위임.
- **제10조(감청설비 인가)**: 감청설비를 제조·수입·판매·소지·사용하려면 과학기술정보통신부장관 인가 필요(국가기관 제외) — 단, [시행령](enforcement_decree.md) 제3조가 SKT의 통상적인 전기통신사업용 설비·무선국 설비·적합성평가 받은 기자재를 감청설비에서 **제외**하여 일반 통신망 설비는 인가 대상이 아님을 명확히 함.

# 실무 체크리스트

- [ ] 수사기관의 통신사실확인자료 제공 요청 시 법원 허가서 확인 — 미확인 상태로 제공 시 형사책임(제17조)
- [ ] 자료제공현황 연 2회 과기정통부 보고 + 대장·관련자료 7년 보관(제13조⑦) 누락 여부 점검
- [ ] 긴급 제공 후 사후 허가 불승인 시 즉시 폐기 프로세스 확보(제13조④)
- [ ] 통신제한조치 위탁 집행 요청 접수 시 허가서 표지 사본·신분증표 확인, 대상자 번호 불일치 시 거부
- [ ] 자사 통신망 설비(무선국·사업용 설비)는 감청설비 인가 대상이 아님을 전제로 하되, 별도 감청 관련 장비 도입 시 인가 필요 여부 재확인
