# 요약

적합성평가 대상기자재의 전자파적합성(EMC) 시험을 실제로 수행할 때 적용해야 하는 **시험표준(KS·KN·IEC 등)을 항목별로 지정**한 국립전파연구원 공고이다. 「방송통신기자재등의 적합성평가에 관한 고시」 **제4조제3항**이 근거이며, 2025년 7월 11일 발령되어 **발령 후 1개월이 경과한 날인 2025년 8월 12일부터 시행**된다.

본문은 **제1조~제4조 4개 조문뿐**으로 매우 짧다. 원문 덤프에서 확인되는 장 제목은 **「제2장 세부 시험방법」**(제3조 앞) 하나이며, 제1조(목적)·제2조(적용범위)가 총칙에 해당한다. 실질 내용은 두 조문에 집중되어 있다 — **제3조**는 측정기구·시험장·공통 측정방법 등 일반사항에 대해 **제1항~제22항**에 걸쳐 KS 표준을 지정하고, **제4조**는 대상기기별로 **제1항~제28항 + 제3항의2·의3·의4, 제4항의2**(총 32개 항)에 걸쳐 시험표준을 지정하며 그중 **제11항이 무선설비기기류를 제1호~제15호로 세분**한다.

즉 「전자파적합성 기준」(고시 제2025-22호)이 각 기기가 만족해야 할 **허용기준(한도값)**을 정한다면, 이 공고는 그 적합 여부를 **측정하는 방법과 인용표준**을 정한다. 다만 **별표 1·2(태양광 발전시스템용 전력변환기, 전기철도기기류 시험방법)는 본문이 아니라 국가법령정보센터의 별도 첨부파일로만 제공**되어, 조문 텍스트에는 "자세한 내용은 상단 메뉴 버튼을 이용하십시오"라는 안내 문구만 남아 있다(법제처 DRF API 취득본에서도 동일). 해당 기기를 다룰 때는 첨부파일을 별도로 내려받아야 한다.

경과조치 구조에도 주의가 필요하다. **부칙 제2조**에 따라 시행 당시 **종전의 제3조·제4조에 따라 적합성평가 시험을 이미 한 경우에는 개정 규정에도 불구하고 종전 규정에 따른다** — 적용 규정이 **시험을 한 시점**을 기준으로 갈리므로 성적서 일자 확인이 필요하다. 또한 **부칙 <제2024-100호>는 제4조제14항 개정규정을 2023년 8월 17일부터 소급 적용**하도록 정하고 있다.

# 적용 범위

- 「방송통신기자재등의 적합성평가에 관한 고시」 **제3조**에 따른 **적합성평가 대상기자재의 전자파적합성 시험**(이하 "적합성 시험")에 적용한다(제2조).
- 실제 수범자는 EMC 시험을 수행하는 지정시험기관과, 적합인증·적합등록을 신청하는 제조사·수입사이다.
- **제4조제11항(무선설비기기류)에서 해상업무용 무선설비와 항공기 탑재 무선설비는 제외**된다(같은 항 단서). 해상·항공은 별도 항(제19항, 제27항)에서 다룬다.

## 별표

별표 **2건**, **별지 서식 없음**. **두 별표 모두 본문이 첨부파일로만 제공되며 조문 텍스트에는 내용이 없다** — 법제처 DRF API 취득본(`document_chunks`)에도 *"[별표 N] … 의 자세한 내용은 상단 메뉴 버튼을 이용하십시오"* 안내 문구만 수록되어 있음을 확인했다. **RAG 색인에 실체가 없으므로 AI 답변으로 그 내용을 구성할 수 없다.**

## 부칙

### 부칙 <제2025-50호, 2025. 7. 11.> — 현행

# 실무 체크리스트

**SKT(이동통신) 직접 접점**

- [ ] **이동통신 기지국·중계기·보조기기**는 제4조제11항 **제9호 → KS X 3135:2020**으로 시험한다. **단말기·보조기기**는 **제3호 → KS X 3129:2020**. 두 표준을 혼동하지 말 것.
- [ ] 무선설비는 **제1호 공통(KS X 3124:2024)** 적용 여부를 먼저 확인한 뒤 세분류 호를 매칭한다.
- [ ] **소출력 계열이 3개 호로 갈린다** — 무선 데이터 통신용 특정 소출력(제2호, 3126), 일반 특정 소출력(제7호, 3125), 음성·음향 전송용 특정 소출력(제8호, 3130).
- [ ] 위성 휴대 통신용 무선설비는 제15호(3139), TRS는 제10호(3127, 간이 무선국과 같은 표준).
- [ ] **해상업무용·항공기 탑재 무선설비는 제11항 적용 대상이 아니다** — 각각 제19항(KS X 3140 / KS C IEC 60533), 제27항(KS C 9993)으로 간다.
- [ ] 무선전력전송(WPT) 기기 **장해방지**는 제20항 **KS X 3143:2020**(무선설비 계열 표준번호와 유사하므로 표기 주의).

**공통 절차**

- [ ] 시험 대상기기 종류를 확정하고 제4조에서 해당 항(제3항의2~의4, 제4항의2 포함)의 시험표준을 특정한다.
- [ ] 일반 측정기구·시험장·공통 측정방법은 제3조 제1항~제22항의 KS 계열 표준으로 셋업하고, **인용 표준의 판(연도)까지** 일치시킨다.
- [ ] **별표 1(태양광 전력변환기)·별표 2(전기철도기기류)** 대상이면 국가법령정보센터에서 **첨부파일을 별도로 내려받아** 상세 방법을 확보한다(조문 본문·RAG 색인에 내용 없음).
- [ ] **2025. 8. 12. 이전에 시험을 완료한 건**은 부칙 제2조에 따라 종전 규정 적용 — 성적서의 **시험 수행 일자**를 확인한다.
- [ ] 제4조제14항(멀티미디어기기 장해방지, KS C 9832) 관련 건은 **2023. 8. 17.부터 소급 적용**되는 개정임을 확인한다(부칙 제2024-100호 제2조).
- [ ] 한도값(합격 여부)은 이 공고가 아니라 「전자파적합성 기준」(고시 제2025-22호, 2026. 7. 1. 시행)의 별표에서 확인한다. 시험방법과 기준의 시행일이 다르므로 두 문서를 함께 대조한다.
