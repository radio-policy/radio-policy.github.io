# 요약

「전파법」 제58조의2 등 및 전파법 시행령 제77조의2~제77조의8 등의 위임에 따라 방송통신기자재등의 적합성평가 대상기자재와 세부절차를 규정한 국립전파연구원 고시(본체)이다. 과기정통부고시(정책 총괄)와 병존하는 **실무 집행 규정**으로, 국립전파연구원장(원장)이 신청·심사·교부·사후관리 전 과정을 수행한다. 세 가지 적합성평가 유형(적합인증·적합등록·자기적합확인)과 잠정인증, 변경·면제·사후관리 절차, 표시기준(별표 5, KC마크), 대상기자재 분류표(별표 1)를 담고 있으며 조문 체계는 과기정통부고시 판본과 동일하다. **현행판은 국립전파연구원고시 제2026-4호(2026.7.24. 시행)이다.**

> **직전판(제2025-22호, 2026.7.1. 시행) 대비** — 제1조~제32조의 **조문 본문은 실질적으로 동일**하다. 직전판에서 신설된 승강장안전문(PSD) 레이저/라이다 센서 관련 규정(제10조제1항제2호 다목 → 별표 1 제11호 사목 6) 해당 기자재는 별표 4 제3호 사용자안내문 포함)도 그대로 유지되고 있다. **따라서 이번 개정의 실질 변경은 별표 1(대상기자재) 등 별표에 있는 것으로 보이며, 별표는 법제처 조문 API 응답에 포함되지 않으므로 국가법령정보센터 별표 원본을 직접 대조해야 한다.**

# 적용 범위

- 적용 대상: 전파법 제58조의2제1항에 따른 방송통신기자재등 전반. **별표 1**이 11개 대분류로 대상기자재를 지정하고 기기별 평가유형·적용분야를 표시.
- 대상기자재 3분류(제3조): ①영 제77조의2제1항 **적합인증** 대상 ②영 제77조의3제1항 **적합등록** 대상 ③영 제77조의3제2항 **자기적합확인** 대상.
- 소관·집행: 국립전파연구원장(정보통신적합성평가과). 대상기자재 분류위원회 구성·운영(제3조의2).
- 적합성평가기준(제4조): 공통 EMC + 개별기준[무선(전파법 제37·45조), 유선(방송통신발전기본법·방송법·IPTV법·전기통신사업법), 전자파 인체보호(SAR·전자파강도)].

# 주요 내용(구조화)

## 제1장 총칙 (제1~4조)
- 정의(제조자·제조국가·사후관리·기본모델·파생모델·무선 송수신용 부품·동일기자재·고유번호 등), 대상기자재 3분류(제3조), **분류위원회 구성(제3조의2)**, 적합성평가기준의 적용(제4조).

## 제2장 적합인증 (제5~7조)
- 사전 심사형. **신청서류(제5조제1항)** — ①적합인증신청서(별지 1) ②사용자설명서(한글본: 제품개요·사양·구성·조작방법) ③시험성적서(지정시험기관장 발행 / 원장 발행 / MRA 체결국 시험기관 중 원장이 인정한 기관의 장 발행 중 하나) ④외관도(전면·후면·연결부·적합성평가표시 식별 가능한 사진) ⑤부품 배치도 또는 사진(부품번호·사양 식별 가능) ⑥회로도(적합성평가를 받은 '무선 송·수신용 부품'을 구성품으로 쓰면 해당 부분 생략 가능, 유선분야는 전원 및 기간통신망 직접 접속부의 회로도) ⑦대리인 지정(위임)서(별지 4).
- **다중 공급업체 동일부품(제5조제2항)** — 명칭·형식기호·기능이 동일한 부품을 선택적으로 쓰는 경우 부품 목록과 전기적 특성 동일성 증명자료(회로소자는 특성 비교표, 시스템 구성품은 시험성적서) 제출.
- 심사(제6조: 서류·기준적용·시험성적서 유효성), 인증서 교부·공고(제7조).

## 제3장 적합등록 (제8~10조)
- 신청 즉시 등록(제8·9조). **보관서류(제10조제1항)** — ①제8조제1항 제2·3호 서류 ②사용자설명서(제품개요·사양·구성·조작방법 포함). 다음 기자재는 **별표 4 사용자안내문**을 포함해야 한다: 별표 1 제11호 **가목·바목·사목 1)** → 별표 4 **제1호** / 제11호 **비고 제2호 적용** 기자재 → 별표 4 **제2호** / 제11호 **사목 6)**(승강장안전문 레이저·라이다 센서) → 별표 4 **제3호** ③시험성적서(지정시험기관장 / 원장 / MRA 인정기관장 발행, 별지 제15호 구성품 확인서, 또는 **IECEE CB인증서** — 다만 별표 1 제11호의 특정 목·호에 해당하고 지정시험기관장이 국내 적합성평가기준 적합을 확인해 발행한 시험성적서가 있는 경우로 한정).
- 실무 영향: **PSD 레이저/라이다 센서(별표 1 제11호 사목 6))는 별표 4 제3호 사용자안내문(광대역 방사성 RF 전자기장 내성 적용값 표기)을 사용자설명서에 반드시 포함**해야 한다.

## 제4장 자기적합확인 (제11~12조)
- 자기적합확인 선언서 작성·홈페이지 공개(제11조), 보관서류(제12조).

## 제5장 잠정인증 (제13~16조)
- 신기술 기자재(법 제58조의2제9항) 대상. 신청(제13조), 심사(제14조), 잠정인증서 교부·유효기간·허용조건(제15조), **잠정인증심사위원회 구성(제16조)**.

## 제6장 변경 (제17~19조)
- 변경사항의 범위(제17조) — 기준 관련 변경(회로·구성품·부품소자·SW 시험항목·주파수)과 기준 무관 변경(파생모델명·제조자/국가·상호 등), 변경신고(제18조), 처리(제19조).

## 제7장 면제 (제20~22조)
- 면제의 세부범위(제20조: 수출용·선박기자재·아마추어무선·조립컴퓨터·과학실습세트·산업용 등), 면제절차(제21조), 절차·서류 간소화 및 동일기자재 신청(제22조).

## 제8장 조사·조치 (제23~25조)
- **사후관리(제23조)**, **수입기자재의 조사·시험 방법(제23조의2)** — 영 제117조의2에 따른 적합성평가기준 준수여부 확인 시험은 제24조제2~6항을 준용하고, **조사 내용과 결과를 5년간 보관**. **사후관리 시험(제24조)**, **부적합 보고(제25조)**.

## 제9장 보칙 (제26~32조)
- **표시(제26조, 별표 5)** — KC마크, 번호체계, 소형기자재 간소화, e-labelling. 국내 제조 출고 전·수입 통관 전 완료.
- **해지(제27조)**, **재발급(제28조)**.
- **처리기간(제29조)** — **즉시처리**: 적합성평가 식별부호 신청(제5조), 적합등록 신청(제8조), 적합등록 변경신고(제17조제1항 및 제17조제2항 제1·2호 해당분), 적합성평가 해지(제27조), 인증서 재발급(제28조), 수입 기자재 통관확인(제31조). **1일 이내**: 적합성평가 면제확인(제21조). **5일 이내**: 적합인증 신청(제5조), 적합인증 변경신고, 적합등록 변경신고(제17조제2항제3호 해당분), 동일기자재의 적합인증·적합등록 신청(제22조제3항). **30일 이내**: 잠정인증 신청(제13조). 시험성적서 유효성 확인 소요기간은 산입 제외, 잠정인증은 **1회에 한해 15일 연장** 가능(사유·예상기간 서면 사전 통보).
- **국내대리인 지정(제30조)**, **수입 기자재 통관확인(제31조)**, **재검토 기한(제32조)** — **2021년 1월 1일 기준 3년마다**(매 3년이 되는 해의 12.31.까지).

# 별표·서식 목록

- [별표 1] 적합성평가 대상기자재(제3조 관련): 1.해상업무용 / 2.항공업무용 / 3.간이무선국 등 기타 업무용 / 4.전기통신사업용 / 5.신고면제 무선국용 / 6.기타 무선 / 7.단말장치 / 8.유선방송국 / 9.IPTV / 10.방송공동수신 / 11.전자파장해 기기(가.전파응용~차.기타 특수조건). **제11호 사목 6)에 승강장안전문(PSD) 레이저/라이다 센서.** — **이번 개정의 실질 변경 지점으로 추정, 원본 대조 필요**
- [별표 2] 삭제, [별표 3] 삭제
- [별표 4] 사용자안내문(제10·12조 관련): 제1호 업무용 / 제2호 구성품 조합 / **제3호 PSD 센서 — 광대역 방사성 RF 전자기장 내성 기준(20/28/38/56/80 V/m 중 적용값) 표기**
- [별표 5] 적합성평가 표시기준 및 방법(제26조): KC마크, 번호체계, 소형기자재 간소화, e-labelling(디스플레이·QR코드)
- [별표 6] 소비자 안내문(제20조 관련)
- [별표 7] 형식기호 표시방법
- [별지 1~23] 신청·인증·등록·선언·변경신고·면제·구성품확인·부적합 관련 서식

> 별표·별지 본문은 법제처 조문 API 응답에 포함되지 않는다. 대상기자재 분류·표시기준·안내문 문구를 인용할 때는 국가법령정보센터 별표 원본을 확인할 것.

# 실무 체크리스트

- [ ] **별표 1을 직전판(제2025-22호)과 대조해 대상기자재 신설·이동·삭제를 확인했는가** — 조문 본문은 동일하므로 이번 개정의 영향은 별표에 있다
- [ ] 별표 1에서 해당 기자재의 대분류·기기부호·적용분야(EMC/무선/유선/SAR/전자파강도)와 평가유형(적합인증/적합등록/자기적합확인)을 확인
- [ ] 적합인증 신청 시 7종 서류(신청서·사용자설명서 한글본·시험성적서·외관도·부품배치도·회로도·대리인지정서) 구비. 무선 송·수신용 부품 사용 시 회로도 생략 가능 여부 확인
- [ ] 다중 공급업체 동일부품을 쓰는 경우 부품 목록 + 전기적 특성 동일성 증명자료 준비(제5조제2항)
- [ ] 적합등록 기자재의 사용자설명서에 **별표 4 사용자안내문(제1호/제2호/제3호 중 해당분)**을 포함했는가 — 특히 PSD 레이저/라이다 센서는 제3호 필수
- [ ] IECEE CB인증서를 활용하려면 별표 1 제11호의 허용 범위에 해당하고 지정시험기관장의 국내기준 적합 확인 시험성적서가 있는지 확인
- [ ] 처리기간 구분(즉시 / 1일 / 5일 / 30일)에 맞춰 출시 일정 수립. 잠정인증은 15일 연장 가능성 반영
- [ ] 표시는 국내 제조 출고 전, 수입 통관 전 완료(제26조)
- [ ] 수입기자재 조사·시험 대응(제23조의2) 및 관련 자료 5년 보관
- [ ] 이 고시는 국립전파연구원 집행 본체 고시이며, 과기정통부고시(정책 총괄)와 동일 체계로 상호 참조·적용됨을 인지
