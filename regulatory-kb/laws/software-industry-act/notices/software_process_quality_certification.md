# 요약

「소프트웨어 진흥법」 제21조·시행령 제18조~제22조·시행규칙 제8조~제11조에서 위임한 **소프트웨어프로세스 품질인증제도**의 운영 세부사항을 정한 고시다(제1조). 7개 장 15개 조(제8조의2·제8조의3 삭제)와 별표4·별지4로 구성된다. 인증등급은 **1등급(개발 차원)·2등급(프로젝트 차원)·3등급(조직 차원)**이며, 2025-21호 개정으로 종전 2단계(2·3등급)에서 **1등급이 신설**됐다(제4조). 인증기관은 장관이 지정하며 현재 **정보통신산업진흥원(NIPA)** 1곳이다(제6조·별표4).

# 적용 범위

- **시행일**: 2025.4.30.(제2025-21호, 발령한 날부터 시행).
- **대상**: 인증신청 기업·조직, 인증기관, 인증심사원·선임심사원, 인증심의위원.
- **재검토**: 2021.1.1. 기준 매 3년 → 다음 시한 **2026.12.31.**
- **SKT 접점**: SKT가 개발조직으로서 인증을 직접 취득하거나, 협력업체 평가·선정 기준으로 인증등급을 활용하는 수요자 관점.

# 주요 내용(구조화)

## 제1조·제2조 (목적·정의)
목적은 위와 같음. 소프트웨어프로세스·품질인증·인증신청인·인증기관·**품질활동 실적자료** 등 10개 용어 정의.

## 제3조~제5조 (인증기준·등급·비용)
인증기준은 **별표1**(영역1 관리~영역5 개선). **1등급**=영역2, **2등급**=영역1~3, **3등급**=영역1~5 충족(제4조). 비용 = 신청관리비+인증심사비+직접경비(제5조·별표2).

## 제6조·제7조 (인증기관 지정·역할)
장관이 지정심사(별표3) 후 지정, 현재 지정기관은 **정보통신산업진흥원**(별표4, 2009.1.15. 지정). 인증기관은 운영절차 문서화, 심의회 구성·운영, 심사원 관리 의무.

## 제8조 (인증 신청)
인증신청서 제출 → 인증기관이 결격 없으면 심사계획 통보. 제8조의2·제8조의3 삭제.

## 제9조·제10조 (인증 심사·심사원)
심사팀(선임심사원+심사원)이 심사 → 심사결과보고서(별지1) → 인증심의회 제출. **3등급 신청 후 영역1~3만 충족 시 2등급으로 심의·의결**(강등 부여). 불복 시 통보일로부터 **10일 이내** 이의신청(별지3), 인증기관 **10일 이내** 처리 통보. 심사원은 공학경력 5년(또는 PM·컨설팅 3년)+교육이수, 선임심사원은 심사실적 5회+공학 10년 등 요건.

## 제11조·제12조 (인증심의회)
위원장 1인 포함 3~10인, 3인 출석+2/3 찬성 의결. 신청인 조직 임직원·심사수행 이력자는 제척. 위원 임기 2년, 연임 가능.

## 제13조~제15조 (인증서·연장·재검토)
기준 충족 시 인증서 발급, 변경 시 별지4 제출(제13조). 유효기간 연장은 만료 3개월 전 신청+매년 품질활동 실적자료 제출(제14조). 재검토기한은 2021.1.1. 기준 매 3년(제15조).

# 실무 체크리스트

- [ ] 신청 등급(1·2·3등급)에 필요한 별표1 영역 충족 여부를 사전 점검한다.
- [ ] 인증기관이 **정보통신산업진흥원** 1곳뿐이므로 심사 일정을 사전 확인한다.
- [ ] 인증비용(신청관리비+인증심사비+직접경비)을 사전 견적한다.
- [ ] 협력업체 평가 시 3등급 신청이 영역1~3만 충족되면 **2등급으로 강등** 부여될 수 있음을 반영한다.
- [ ] 인증 취득 후 매년 품질활동 실적자료 제출, 만료 3개월 전 연장신청 일정을 관리한다.
- [ ] 이의신청은 통보일로부터 **10일 이내**로 관리한다.
- [ ] 재검토기한(**2026.12.31.**) 전후 개정 여부를 모니터링한다.
