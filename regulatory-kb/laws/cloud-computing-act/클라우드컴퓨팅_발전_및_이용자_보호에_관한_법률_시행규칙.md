# 요약

이 규칙은 「클라우드컴퓨팅 발전 및 이용자 보호에 관한 법률」(이하 "법") 및 같은 법 시행령(이하 "영")에서 위임된 사항과 그 시행에 필요한 사항을 규정한다(제1조). **본문은 제1조부터 제4조까지 4개 조문뿐이며**, 실체적 요건(유효기간, 지정 기준, 사후관리, 수수료)은 모두 영에 있고 이 규칙은 **서식과 표시 도안**만을 정하는 절차·양식 규칙이다.

구체적으로는 ① 보안인증을 받으려는 자가 제출할 신청서(별지 제1호서식)와 발급되는 보안인증서(별지 제2호서식)를 정하고(제2조), ② 인증기관·평가기관으로 지정받으려는 자의 지정 신청서(별지 제3호서식)와 인증기관 지정서(별지 제4호서식)·평가기관 지정서(별지 제5호서식)를 정하며(제3조), ③ 법 제23조의2제3항에 따른 **보안인증 표시 기준을 별표**로 정한다(제4조).

주의할 주체 관계는 다음과 같다. **보안인증 신청서(별지 제1호서식)의 수신처는 "한국인터넷진흥원 또는 인증기관의 장"** 이고, **인증기관·평가기관 지정 신청서(별지 제3호서식)의 수신처는 "과학기술정보통신부장관"** 이다. 보안인증서는 한국인터넷진흥원장 또는 인증기관의 장이 발급하고, 인증기관·평가기관 지정서는 과학기술정보통신부장관이 발급한다. 즉 **서비스 보안인증은 KISA/인증기관이, 기관 지정은 장관이** 처리하는 2원 구조다.

서식상 **보안인증 신청의 처리기간은 240일, 인증기관·평가기관 지정 신청의 처리기간은 120일**이며 지정 신청의 **수수료는 없음**으로 되어 있다. 보안인증서(별지 제2호서식)에는 인증번호가 **"CSAP-　-　호"** 형식으로, 유효기간이 **5년**으로 인쇄된다(유효기간 5년의 근거 규정 자체는 영 제15조의7제1항).

별표(보안인증의 표시 기준)는 표시도안 A·B·C 중 선택 사용, 도형과 문구의 구성, **도형 각 부위별 CMK 색상값 12개 항목**, 문구는 검정색(Cyan 0, Megenta 0, Key 100)·맑은 고딕체 사용, 표시방법 3개 항(같은 배율 조정 가능 / 색상·글씨체 임의 변경 불가 / 알아보기 쉬울 것)을 정한다.

부칙 <제105호, 2023. 1. 10.>은 "이 규칙은 2023년 1월 12일부터 시행한다"는 단일 조문이며, 이후 개정 부칙은 없다(현행본 기준).

- "보안인증기준": 법 제23조제2항에 따른 클라우드컴퓨팅서비스의 정보보호에 관한 기준으로 **관리적·물리적·기술적 보호조치를 포함**한다(제2조제1항 괄호).

- "평가기관": 법 제23조의2제5항제1호에 따른 보안인증기준 적합 여부 확인 평가 업무를 수행하는 기관(제3조제1항 괄호).

# 주요 내용

## 1. 목적(제1조)

이 규칙은 법 및 영에서 위임된 사항과 그 시행에 필요한 사항을 규정함을 목적으로 한다.

## 2. 보안인증의 신청 등(제2조)

**제1항 — 신청**
- **신청 주체**: 법 제23조의2제1항에 따라 보안인증기준에 적합한 클라우드컴퓨팅서비스에 대하여 **인증을 받으려는 자**.
- **제출 서식**: 별지 제1호서식의 신청서.
- **첨부**: 영 제15조의6제1항 각 호의 서류(아래 3종).
- **제출처**: 보안인증에 관한 업무를 수행하는 **한국인터넷진흥원 또는 법 제23조의2제5항에 따라 지정된 기관(인증기관)** 에 **제출해야 한다**(기속).

**영 제15조의6제1항 각 호(첨부서류 3종)**
1. 법 제23조제2항에 따른 클라우드컴퓨팅서비스의 정보보호에 관한 기준(관리적·물리적·기술적 보호조치 포함)에 **적합한지 여부를 확인할 수 있는 서류** 1부
2. **보안인증 대상 목록** 1부
3. 그 밖에 보안인증에 필요한 사항으로서 **과학기술정보통신부장관이 고시하는 사항**에 관한 서류

**제2항 — 보안인증서**
- 영 제15조의6제7항에 따른 **클라우드컴퓨팅서비스 보안인증서는 별지 제2호서식**과 같다.
- 발급 주체는 **한국인터넷진흥원 또는 인증기관**이며(영 제15조의6제7항), 보안인증위원회가 인증평가 결과를 보안인증기준에 적합하다고 **의결한 경우**에 발급하고 그 사실을 해당 기관 홈페이지에 게시한다.

**별지 제1호서식(클라우드컴퓨팅서비스 보안인증 신청서)의 기재사항**

| 구분 | 항목 |
|------|------|

- 업체명, 대표자, **보안인증 대상**, **보안인증 유효기간: 5년**(시작일~종료일 기재)

- 규격: 210mm×297mm[백상지(150g/㎡)]

## 3. 인증기관 및 평가기관 지정 신청 등(제3조)

**제1항 — 지정 신청서**
- 영 제15조의10제1항 각 호 외의 부분에 따라 **인증기관** 또는 법 제23조의2제5항제1호에 따른 보안인증기준 적합 여부를 확인하기 위한 **평가 업무를 수행하는 기관(평가기관)** 으로 **지정받으려는 자**가 제출해야 하는 지정 신청서는 **별지 제3호서식**과 같다.

**제2항 — 지정서**
영 제15조의10제4항에 따른 지정서는 다음 각 호의 구분에 따른다.
1. **인증기관 지정서: 별지 제4호서식**
2. **평가기관 지정서: 별지 제5호서식**

**별지 제3호서식([인증기관/평가기관] 지정 신청서)의 기재사항**

| 구분 | 항목 |
|------|------|
| 처리기간 | **120일** |
| 신청 구분 | [ ] 신규 / [ ] **유효기간 연장** |
| 신청인 | 업체명(상호), 사업자등록번호, 성명(대표자), 전화번호, 주소(주된 사무소의 소재지), 인터넷 홈페이지 주소, 전자우편 주소 |
| 인력 | **총 직원 수** / **인증평가를 수행하는 직원 수(평가기관만 해당)** — 모두 **신청일을 기준으로** 작성 |
| 수신처 | **과학기술정보통신부장관 귀하** |
| 근거 | 법 제23조의2제5항·제6항 및 영 제15조의10제1항 |
| 수수료 | **없음** |
| 규격 | 210mm×297mm[백상지(80g/㎡) 또는 중질지(80g/㎡)] |

**별지 제3호서식의 첨부서류·확인사항**
1. 법인의 정관 또는 단체의 규약(법인 또는 단체만 해당) 1부
2. 영 제15조의10제2항에 따른 **지정 기준을 갖추었음을 증명하는 서류** 각 1부
3. 그 밖에 인증기관 또는 평가기관 지정에 필요한 사항으로서 과학기술정보통신부장관이 정하여 고시하는 서류
- **담당 공무원 확인사항**: 법인 등기사항증명서(법인인 경우만 해당) → 신청인이 제출하는 첨부서류가 아니라 **행정정보 공동이용으로 공무원이 확인**하는 항목이다.

**별지 제3호서식의 처리절차(5단계)**
신청서 작성(신청인) → 접수 → 심사 → 지정 여부 결정 → 지정서 발급(이하 **과학기술정보통신부**)

**별지 제4호·제5호서식(지정서)의 기재사항**

|------|--------------------------|--------------------------|
| 제목 | 클라우드컴퓨팅서비스 보안인증 **인증기관** 지정서 | 클라우드컴퓨팅서비스 보안인증 **평가기관** 지정서 |
| 기재 | 등록번호, 유효기간, 업체명, 대표자 | 등록번호, 유효기간, 업체명, 대표자 |
| 근거 문언 | 법 **제23조의2제5항** 및 영 제15조의10제4항 | 법 **제23조의2제6항** 및 영 제15조의10제4항 |
| 발급자 | 과학기술정보통신부장관(직인) | 과학기술정보통신부장관(직인) |

※ 제4호·제5호서식의 본문 문언은 법률명을 "「클라우드컴퓨팅 발전 및 이용자 보호 **등에** 관한 법률」"로 적고 있으나, 정식 법률명은 「클라우드컴퓨팅 발전 및 이용자 보호에 관한 법률」이다(서식상의 표기 오류).

## 4. 보안인증의 표시(제4조 및 별표)

**제4조 본문**: 법 제23조의2제3항에 따라 **보안인증을 받은** 클라우드컴퓨팅서비스에 대한 보안인증의 **표시 기준은 별표와 같다.**

### 4-1. 표시도안(별표 제1호)
- 가. 표시도안은 **A, B 또는 C 중에 사용 목적에 맞게 선택하여 사용할 수 있다.**
- 나. 표시도안은 **도형과 문구**로 구성된다.

**1) 도형 — 가) 도형의 색상**(별표 제1호나목1)가), 표기는 원문의 Cyan/Megenta/Key 값 그대로)

| 구분 | 색정보 |
|------|--------|
| 구름 내부 위쪽 | 옅은 하늘색(Cyan 7, Megenta 4, Key 2) |
| 구름 내부 아래쪽 | 옅은 하늘색(Cyan 25, Megenta 12, Key 8) |
| 구름 테두리 | 하늘색(Cyan 29, Megenta 11, Key 5) |
| 자물쇠 | 파란색(Cyan 74, Megenta 30, Key 32) |

**2) 문구**(별표 제1호나목2))
- 가) 문구의 색상은 **검정색(Cyan 0, Megenta 0, Key 100)** 을 사용한다.
- 나) 문구의 **글씨체는 맑은 고딕체**를 사용한다.

### 4-2. 표시방법(별표 제2호)
- 가. 표시도안의 크기는 용도에 따라 **같은 배율로 조정할 수 있다.**
- 나. 표시도안의 **색상 및 글씨체는 임의로 변경할 수 없다.**
- 나(원문 항목 기호 중복). 표시도안은 **알아보기 쉬워야 한다.**

※ 원문 별표 제2호는 항목 기호가 "가. / 나. / 나."로 되어 있어 마지막 항목의 기호가 "다."가 아닌 "나."로 표기되어 있다(법령 원문의 표기 그대로).

# 실무 체크리스트

## A. 보안인증(CSAP) 신청 — 제2조, 별지 제1호서식

- [ ] 신청서는 **별지 제1호서식**으로 작성하고, **한국인터넷진흥원 또는 지정 인증기관**에 제출한다(제2조제1항). 제출처는 과학기술정보통신부장관이 **아니다** — 기관 지정 신청과 혼동하지 않는다.
- [ ] 신청 구분에서 **최초 신청 / 갱신 신청**을 정확히 선택한다. 갱신은 영 제15조의7제2항에 따라 **유효기간 만료 6개월 전까지** 신청해야 하므로, 만료 6개월 전 시점을 사내 캘린더에 등록한다.
- [ ] 첨부 3종(정보보호 기준 적합 확인 서류 / 보안인증 대상 목록 / 장관 고시 서류)을 준비했는가(영 제15조의6제1항). **"보안인증 대상 목록"** 이 실제 인증 범위를 확정하므로, 상용 서비스 라인업과 대조한다.
- [ ] **처리기간 240일**을 전제로 공공 조달 일정(국가기관등은 보안인증 서비스를 우선 고려해야 함, 법 제20조제2항)을 역산한다.
- [ ] 서식상 처리절차에서 **접수·예비점검과 인증평가는 평가기관**, **인증위원회 심의와 보안인증서 발급은 인증기관**이 수행한다 — 문의·이의 창구를 단계별로 구분해 둔다.
- [ ] **수수료 납부는 3단계(인증평가 전)** 에 발생한다. 중소기업이면 영 제15조의9제2항에 따른 **수수료 전부·일부 지원** 가능 여부를 사전에 확인한다.
- [ ] 발급받은 보안인증서(별지 제2호서식)의 **"보안인증 대상"과 유효기간(5년) 표기**를 보관하고, 마케팅 자료에 쓰는 인증 범위가 이 기재와 일치하는지 대조한다.

## B. 보안인증 표시 사용 — 제4조, 별표 (위반 시 과태료)

- [ ] 표시도안은 **A·B·C 중 사용 목적에 맞게 선택**해 사용한다(별표 제1호가목). 임의 변형본을 만들지 않는다.
- [ ] 도형 색상 14개 항목을 원문 값대로 적용했는가. 특히 **"방패 바깥쪽 테두리"(C55 M23 K20 → C68 M48 K63 그라데이션)와 "바깥 테두리"(C88 M44 K34)는 별개 항목**이다.
- [ ] 그라데이션 4개 항목(방패 바깥쪽 테두리 / 안쪽 원형 / 상위 반원 테두리 / 하위 반원 테두리)의 **진해짐·연해짐 방향**을 반대로 적용하지 않았는가.
- [ ] 문구는 **검정색(C0 M0 K100) + 맑은 고딕체** 고정이다. 사내 브랜드 서체로 치환하면 별표 위반이다.
- [ ] 크기 조정은 **"같은 배율"** 로만 가능하다 — 가로·세로 비율을 다르게 늘리는 것은 허용되지 않는다(별표 제2호가목).
- [ ] **인증받지 않은 서비스·인증 범위를 벗어난 상품에 CSAP 표시나 유사 표시를 하지 않도록** 영업·마케팅 자료를 통제한다. 이 금지는 이 규칙이 아니라 **법 제23조의2제4항**에 있고, 위반 시 **1천만원 이하 과태료**(법 제37조제1항제1호)다. "누구든지"가 수범자이므로 대리점·리셀러 자료도 점검 대상이다.

## C. 인증기관·평가기관 지정 신청(해당 사업을 검토하는 경우) — 제3조, 별지 제3호서식

- [ ] 지정 신청서는 **별지 제3호서식**으로 **과학기술정보통신부장관에게** 제출한다(제3조제1항, 영 제15조의10제1항). 신청 구분은 **신규 / 유효기간 연장** 중 선택.
- [ ] 총 직원 수와 **인증평가 수행 직원 수(평가기관만 해당)** 는 **신청일 기준**으로 작성한다 — 지정 기준(영 제15조의10제2항제2호, **전담 상시 근무 전문인력 4명 이상**) 충족 여부가 이 숫자로 판단된다.
- [ ] 첨부는 정관·규약, 지정 기준 충족 증명서류, 장관 고시 서류 3종이며 **법인 등기사항증명서는 담당 공무원 확인사항**이므로 별도 제출 대상이 아니다.
- [ ] **수수료 없음**, **처리기간 120일**. 심사 과정에서 **현장조사 또는 추가 서류 제출 요청**이 있을 수 있다(영 제15조의10제3항).
- [ ] 지정되면 **인증기관은 별지 제4호서식(근거: 법 제23조의2제5항)**, **평가기관은 별지 제5호서식(근거: 법 제23조의2제6항)** 지정서를 받는다. 두 지정서의 근거 항이 다르므로 신청 단계에서 어느 지위를 원하는지 명확히 한다.
- [ ] 지정 기준은 이 규칙이 아니라 **영 제15조의10제2항**에 있고 **2025. 12. 23. 개정**되었다 — 규칙(2023. 1. 12. 시행) 본문만 보고 판단하지 않는다.
