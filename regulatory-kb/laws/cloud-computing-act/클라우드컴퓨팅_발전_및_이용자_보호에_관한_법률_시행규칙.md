# 요약

본 시행규칙은 「클라우드컴퓨팅 발전 및 이용자 보호에 관한 법률」의 위임사항을 구체화하며, 클라우드컴퓨팅서비스 보안인증의 신청절차, 인증기관 및 평가기관 지정, 보안인증 표시 기준을 정하고 있다. 보안인증은 관리적·물리적·기술적 보호조치를 포함한 정보보호 기준에 적합한 서비스에 대해 한국인터넷진흥원 또는 지정 인증기관이 발급하며, 5년 유효기간을 갖는다.

---

# 적용 범위

- **적용 대상**: 클라우드컴퓨팅서비스 제공사업자
- **관할 기관**: 과학기술정보통신부, 한국인터넷진흥원, 지정 인증기관·평가기관
- **적용 범위**: 보안인증 신청부터 발급, 표시까지 전 과정

---

# 주요 내용

## 1. 보안인증 신청 (제2조)

### 신청 요건
- 법 제23조의2제1항에 따라 정보보호 기준(관리적·물리적·기술적 보호조치 포함)에 적합한 클라우드컴퓨팅서비스
- 신청 기관: 한국인터넷진흥원 또는 법 제23조의2제5항에 따라 지정된 인증기관

### 신청 절차
- 별지 제1호서식 신청서에 영 제15조의6제1항 각 호 서류 첨부
- 처리기간: 240일
- 구분: 최초 신청 또는 갱신 신청

### 첨부서류
1. 정보보호 기준 적합성 확인 서류
2. 보안인증 대상 목록
3. 과학기술정보통신부장관이 고시하는 서류

### 보안인증서
- 별지 제2호서식(CSAP-호 형식)
- 유효기간: 5년

## 2. 인증기관 및 평가기관 지정 (제3조)

### 지정 신청 대상
- **인증기관**: 보안인증 업무 수행 기관
- **평가기관**: 보안인증기준 적합성 여부 평가 업무 기관

### 지정 신청 절차
- 신청서식: 별지 제3호서식
- 처리기간: 120일
- 신청 구분: 신규 또는 유효기간 연장
- 수수료: 없음

### 지정서 형식
- 인증기관: 별지 제4호서식
- 평가기관: 별지 제5호서식

### 첨부서류
1. 법인 정관 또는 단체 규약
2. 영 제15조의10제2항 지정 기준 충족 증명서
3. 과학기술정보통신부장관이 고시하는 서류
4. 법인 등기사항증명서(법인인 경우)

## 3. 보안인증 표시 기준 (제4조, 별표)

### 표시도안 구성
- **3가지 유형**: A, B, C 중 선택 가능
- **구성 요소**: 도형(구름 + 자물쇠 + 방패) 및 문구

### 도형 색상 사양
- 구름 내부(상): 옅은 하늘색(C7 M4 K2)
- 구름 내부(하): 옅은 하늘색(C25 M12 K8)
- 구름 테두리: 하늘색(C29 M11 K5)
- 자물쇠: 파란색(C74 M30 K32)
- 방패 내부: 흰색(C0 M0 K0)
- 방패 안쪽 테두리: 하늘색(C79 M26 K19)
- 바깥 테두리: 파란색(C88 M44 K34)

### 문구
- 색상: 검정색(C0 M0 K100)
- 글씨체: 맑은 고딕체
- 표기 내용: CSAP, Cloud Security Assurance Program, 클라우드 서비스 보안인증

### 표시 방법
- 용도에 따라 배율 조정 가능
- 색상 및 글씨체 변경 불가
- 알아보기 쉬워야 함

# 실무 체크리스트

## 보안인증 신청 시
- [ ] 별지 제1호서식 작성 (신청인 정보, 서비스명, 신청 구분 명시)
- [ ] 정보보호 기준 적합성 증명서 준비
- [ ] 보안인증 대상 목록 작성
- [ ] 추가 필요 서류(과학기술정보통신부 고시 확인) 준비
- [ ] 한국인터넷진흥원 또는 지정 인증기관에 제출
- [ ] 처리기간(240일) 내 완료 여부 확인

## 인증기관/평가기관 지정 신청 시
- [ ] 별지 제3호서식 작성 (신청 구분 선택)
- [ ] 법인 정관/단체 규약 제출
- [ ] 지정 기준 충족 증명서 준비
- [ ] 직원 현황 작성(신청일 기준)
- [ ] 과학기술정보통신부에 신청
- [ ] 처리기간(120일) 내 지정서(제4호 또는 제5호서식) 수령 확인

## 보안인증 표시 사용 시
- [ ] 표시도안 선택(A, B, C 중 하나)
- [ ] 정확한 색상 사양 확인(CMY-K 값)
- [ ] 맑은 고딕체 사용 확인
- [ ] 로고의 알아보기 쉬움 확인
- [ ] 임의 색상/글씨체 변경 금지
