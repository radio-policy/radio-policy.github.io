# 요약

[인공지능 발전과 신뢰 기반 조성 등에 관한 기본법](../ai_framework_act.md) **제16조제3항**(국가기관등의 인공지능제품·서비스 **우선구매 고려 의무**) 및 [같은 법 시행령](../enforcement_decree.md) **제15조제4항제1호**에 따라, **제품 또는 서비스에 인공지능 또는 인공지능기술이 활용되었음을 확인하는 절차("확인절차")와 그 운영에 필요한 사항**을 정한 과기정통부 고시다(제2026-50호). 부칙 <제2026-50호, 2026.7.21.>에 따라 **2026년 7월 21일 시행**.

본칙은 제1조~제9조로 짧고, 별지 제1호~제4호 서식이 붙는다. 제도의 축은 **확인기관(한국인공지능진흥협회)이 접수·결정·발급하고, 심사기관(TTA)이 기술적 심사를 수행하는 2기관 구조**다.

**⚠️ 이 고시는 고영향 인공지능 확인(법 제33조)과 전혀 다른 절차다.** 법 제33조의 고영향 해당 여부 확인은 **시행령 제25조**가 규율하며 **과기정통부장관**이 직접 처리하고(회신 30일), 이 고시는 **공공조달 맥락에서 "이것이 AI 제품이 맞는가"** 를 확인해 주는 별개 절차로 **확인기관의 장**이 처리한다(결정 15일). 두 절차를 혼동하지 말 것.

# 적용 범위

## 수행 기관 및 정의 (제2조)

| 용어 | 정의 |
|---|---|
| **확인기관** | 법 제26조제1항에 따른 **한국인공지능진흥협회** — 신청 접수·검토·결정·확인서 발급·확인 취소의 주체 |
| **심사기관** | 제품·서비스에 인공지능 또는 인공지능기술이 활용되었는지에 대한 **기술적 심사**를 수행하는 기관으로, 「방송통신발전 기본법」 제34조에 따른 **한국정보통신기술협회(TTA)** |
| **인공지능처리 연산체계** | 데이터로부터 **학습하거나 추론하여 예측·분류·생성 등의 출력을 생성할 수 있도록 설계된 알고리즘 또는 프로그램 등** |

## 확인 제외 대상 (제3조)

다음은 확인 대상에서 제외되며, 해당 제품·서비스에 대한 확인신청이 접수된 경우 **확인기관의 장은 신청을 반려할 수 있다**(의무 반려가 아니라 임의).

1. 법률상 생산·제조 또는 유통이 **금지된** 제품 또는 서비스에 대하여 확인을 신청하는 경우
2. **전자장치가 아닌 제품 등** 인공지능 또는 인공지능기술이 활용되지 않았음이 **명백한** 제품·서비스에 대하여 확인을 신청하는 경우
3. **이미 확인절차가 완료된** 제품·서비스에 대하여 **구성 등의 변경 없이 재차** 확인을 신청하는 경우

# 주요 내용

## 제4조(확인신청)

- **① 신청 주체는 신청인**(확인을 받으려는 자)이며, **확인기관의 장에게** 다음 서류를 첨부하여 신청하여야 한다. **확인기관의 온라인 시스템을 통해 신청할 수 있다.**
  1. 별지 **제1호 서식** 인공지능 제품ㆍ서비스 **확인 신청서**
  2. 별지 **제2호 서식** **열람ㆍ이용동의서**
  3. 별지 **제3호 서식** **개인정보 수집ㆍ이용 및 제3자 제공동의서**
  4. 인공지능 또는 인공지능기술의 **배치 및 데이터 흐름도를 반영한 인공지능 제품ㆍ서비스 구조도**
  5. **알고리즘·데이터 특성·역할에 대한 요약이 포함된 인공지능처리 연산체계 및 기능 명세서**
- **② 선행 요건(가장 자주 누락되는 항목)** — 신청인은 확인 신청을 하는 경우 **사전에 조달청 목록정보시스템(https://goods.g2b.go.kr)에 목록화 요청을 하여 물품목록번호(세부품명번호 및 식별번호)를 부여받아야 한다.** 이 절차가 공공조달과 직결됨을 보여주는 조항이다.
- **③** 확인기관의 장은 신청된 제품·서비스가 **제3조 확인 제외 대상인지를 검토하여야 한다**(의무).
- **④** 신청서류 검토 후 미비 사항이 있으면 **30일 이내의 기간을 정하여** 신청인에게 **보완을 요청할 수 있다**.
- **⑤** 보완이 이루어졌음에도 미비 사항이 있으면 **재보완을 요청하거나 신청을 반려할 수 있다**. (원문은 제5항에서 "제3항에 따라"로 인용하고 있으나 문맥상 제4항 보완을 가리킨다 — 원문 표기 그대로 옮김.)

## 제5조(확인기준 등)

- **①** 확인기관의 장은 확인신청을 받은 때에는 **지체없이 심사기관에 기술적 심사를 요청하여야 한다**.
- **②** **심사기관의 장**은 다음 **7개 기준**에 따라 기술적 심사를 수행하고 **그 결과를 지체없이 확인기관에 통보하여야 한다**.

| 호 | 심사 기준 |
|---|---|
| 1 | 제품 또는 서비스에 **인공지능처리 연산체계가 적용**되어 있을 것 |
| 2 | 적용된 인공지능처리 연산체계가 **학습ㆍ추론 등 인공지능으로서의 특성**을 가지고 있을 것 |
| 3 | 제품·서비스에 입력된 데이터가 연산체계를 거쳐 **유의미한 결과(예측·생성 등)를 출력**할 것 |
| 4 | **구조도상 인공지능(기술)의 위치가 명확**하며, 제품·서비스의 **구동 체계와 결합되어 동작**할 것 |
| 5 | 연산체계가 제품·서비스의 **기능·편의성·접근성·효율성 등에 활용**되고 있음이 확인 가능할 것 |
| 6 | 연산체계가 적용된 **주요 기능이 정상적으로 동작**할 것 |
| 7 | **외부** 인공지능처리 연산체계와 **연동된 경우 호출 로그나 API Key(Application Programming Interface Key)를 확인 가능**할 것 |

→ 외부 LLM API를 호출하는 구조의 서비스는 **제7호가 사실상 유일한 기술 입증 포인트**가 된다.

## 제6조(인공지능 활용 여부 결정) — 기한 구조

- **①** 확인기관의 장은 **제5조제2항의 기술적 심사 결과를 반영하여** 활용 여부를 **결정하여야 한다**.
- **② 원칙: 신청 접수 후 15일 이내 결정.** 제품·서비스의 복잡성 등을 고려하여 15일 이내 결정이 어려운 경우 **30일의 범위에서 한 차례 연장**할 수 있고, 이 경우 **연장 사유와 기간을 통보하여야 한다**.
- **③ 보완이 필요한 경우**: 제출 서류가 누락되었거나 불명확하여 결정이 곤란하면 신청인에게 **30일 이내의 기간을 정하여 보완을 요청할 수 있으며**, 이 경우 **보완이 이루어진 날부터 15일 이내에 결정하여야 한다**.
- **④** 보완이 기간 내에 이루어지지 않은 경우 **제출된 서류만을 가지고 결정할 수 있다**. (원문은 "제2항에 따른 보완"으로 인용하나 보완 규정은 제3항이다 — 원문 표기 그대로 옮김.)
- ※ **별지 제1호 서식의 처리기간란은 "30일"로 표기**되어 있어 본문 제6조제2항의 15일과 다르다. 실제 일정 산정은 **본문 조문(15일 + 30일 범위 1회 연장)** 을 기준으로 하되, 서식 표기 차이를 감안해 확인기관에 확인할 것.

## 제7조(확인서의 발급 등)

- **①** 인공지능(기술)이 활용된 것으로 확인된 경우 확인기관의 장은 별지 **제4호 서식 「인공지능제품·서비스 확인서」를 발급하여야 한다**(기속).
- **②** 발급한 확인서를 **전자적 형태로 보관하여야 하며**, 신청인이 **재발급을 요청하는 경우 재발급하여야 한다**.
- **③ 일괄 확인서** — 제품·서비스에 **적용된 인공지능에는 차이가 없으나 단순한 외형·외관 등의 차이가 있는 다른 제품 모델 또는 서비스 모델**이 존재하는 경우, 해당 모델들을 **일괄 기재하여 하나의 확인서로 발급할 수 있다**. 모델 라인업이 많은 경우 신청 부담을 크게 줄인다.
- 확인서 기재 항목: 제품·서비스 명칭 / 유형(제품·서비스) / 세부품명번호 / 물품식별번호, 그리고 기업명·심사기관·확인번호·확인일자·특기사항. 명의는 **확인기관의 장**.

## 제8조(확인 취소)·제9조(비밀유지의무)

- **제8조** — 신청자가 **거짓이나 부정한 방법**으로 확인을 받은 경우 확인기관은 **확인을 취소하여야 한다**(기속, 재량 없음). 이 경우 **사전에 신청자의 의견을 들어야 한다**.
- **제9조** — 확인기관 및 심사기관의 **임·직원**은 확인 절차 관련 업무수행 중 알게 된 **비밀이나 기업의 영업비밀을 누설하여서는 아니 된다**. (이 고시 자체에는 위반 시 벌칙·과태료 규정이 없다.)

## 별지 서식에서 확인되는 실무 정보

- **별지 제1호(확인 신청서)** — 신청인(상호·법인등록번호 또는 사업자등록번호·대표자·소재지·업무담당자 또는 **국내대리인**), 신청 제품·서비스(연번 / 명칭 / **세부품명번호** / **물품식별번호**), 개요, **인공지능 적용 목적**, **제공 형태(사내 구축형 / SaaS / 기기 / 기타)**, **제품 분류(소프트웨어 / 서비스 / 기기)**, **인공지능 적용 범위**, **핵심 인공지능 기능 명세(기능명·인공지능 역할·입력·출력·참조 위치)**.
  - 작성방법상 "제품·서비스 명칭"은 **조달청 목록화 신청 시 작성한 모델명**을 기재하고, 세부품명번호·물품식별번호는 **사전에 부여받은 번호**를 기재한다(항목이 많으면 붙임서류로 제출 가능).
  - "인공지능 역할"은 **분류·예측·생성·추천 등 기술적 역할**을 명확히, "입력"은 데이터의 **형태(정형/비정형)와 유형(이미지·텍스트·음성 등)** 을 요약 기재.
  - 첨부 제출서류는 **①구조도 ②인공지능처리 연산체계 및 기능 명세서** 2종.
  - **처리절차**: 신청서 작성·제출 → 접수 → **서류심사** → **기술심사** → 결정 → 통지. 처리기관은 **확인기관**.
- **별지 제2호(열람·이용동의서)** — 제출한 **일체의 서류와 확인 대상 제품·서비스**에 대해 **확인기관 및 심사기관의 임·직원이 열람·이용하는 것**에 동의하는 서면.
- **별지 제3호(개인정보 수집·이용 및 제3자 제공동의서)** — 수집 항목 **성명·전화번호·이메일·주소·생년월일 등**, 목적 **인공지능 제품·서비스 확인심사**, **보유기간 10년**. 제3자 제공받는 자는 **확인기관, 심사기관, 조달청**(동일 항목, 보유기간 10년). **동의를 거부할 권리가 있으나 거부 시 심사가 불가하여 신청이 제한될 수 있다**고 안내된다.
- **별지 제4호(확인서)** — 위 제7조 참조.

# 실무 체크리스트

- [ ] 공공부문 납품 대상 AI 제품·서비스를 식별하고, **법 제16조제3항 우선구매 고려** 대상이 되기 위한 확인서 취득 필요성 판단(영 제15조제4항: 우선구매 대상 = **장관이 확인한 제품·서비스**).
- [ ] 신청 **이전에** 조달청 목록정보시스템(goods.g2b.go.kr)에서 **물품목록번호(세부품명번호·식별번호)를 먼저 확보** — 제4조제2항의 선행 요건이며, 신청서 기재란 자체가 이 번호를 전제로 한다.
- [ ] **제품·서비스 구조도**(AI 배치 + 데이터 흐름)와 **인공지능처리 연산체계 및 기능 명세서**를 제5조제2항 **7개 심사기준에 1:1로 대응**되도록 작성 — 특히 기준 4(구조도상 위치 명확 + 구동 체계와 결합)와 기준 6(주요 기능 정상 동작).
- [ ] 외부 LLM/API를 호출하는 구조라면 **호출 로그 또는 API Key 확인 가능성**을 사전에 준비(제5조제2항제7호). 로그 보존 정책과 심사 시점의 제시 방법을 미리 정할 것.
- [ ] 외형·외관만 다른 모델군은 **일괄 확인서**로 묶어 신청(제7조제3항) — 신청서 "연번"란에 순서대로 기재.
- [ ] 처리 일정 역산: **접수 후 15일**(복잡성 등 사유 시 30일 범위 1회 연장), 보완 발생 시 **보완일부터 15일**. 보완 기간(최대 30일)을 놓치면 **제출 서류만으로 결정**되므로 불리한 결정 위험이 있다.
- [ ] 이미 확인받은 제품을 **구성 변경 없이** 다시 신청하면 **반려 대상**(제3조제3호) — 재신청 전 구성 변경 여부를 정리.
- [ ] 신청서·명세서에 **영업비밀**이 포함되는 경우, 제9조 비밀유지의무와 별지 제2호 열람·이용동의서를 전제로 제출 범위를 검토(고시상 누설에 대한 제재 규정은 없으므로 필요 시 계약적 보완 고려).
- [ ] 별지 제3호 동의서로 **개인정보가 조달청까지 제3자 제공**되고 **10년 보유**된다는 점을 담당자에게 고지하고, 담당자 지정 시 내부 개인정보 처리 절차와 정합성 확인.
- [ ] 거짓·부정한 방법에 의한 확인은 **필요적 취소**(제8조) — 명세서상 AI 적용 범위를 과장 기재하지 않도록 기술 검토 후 제출.
- [ ] **고영향 인공지능 확인(법 제33조·영 제25조)과 별개 절차**임을 사내에 명확히 공지 — 처리 주체(장관 vs 확인기관), 기한(30일 vs 15일), 목적(규제 해당성 vs 조달 자격)이 모두 다르다.
