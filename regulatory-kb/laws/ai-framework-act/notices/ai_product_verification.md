# 요약

[인공지능 발전과 신뢰 기반 조성 등에 관한 기본법](../ai_framework_act.md) **제16조제3항**(국가기관등의 인공지능제품·서비스 **우선구매 고려 의무**) 및 [같은 법 시행령](../enforcement_decree.md) **제15조제4항제1호**의 위임에 따라, 제품 또는 서비스에 **인공지능 또는 인공지능기술이 실제로 활용되었는지를 확인하는 절차**를 정한 과기정통부 고시다(제2026-50호, 시행 2026.7.21.).

**주의 — 이 고시는 고영향 인공지능 확인(법 제33조)과 다르다.** 법 제33조의 고영향 해당 여부 확인은 시행령 제25조가 규율하며 과기정통부장관이 직접 처리한다. 이 고시는 **공공조달 맥락에서 "이것이 AI 제품이 맞는가"를 확인**해 주는 별개의 절차다. 두 절차를 혼동하지 말 것.

# 적용 범위 및 수행 기관

- **확인기관**: 법 제26조제1항에 따른 **한국인공지능진흥협회** — 신청 접수·결정·확인서 발급 주체.
- **심사기관**: 「방송통신발전 기본법」 제34조에 따른 **한국정보통신기술협회(TTA)** — 인공지능 활용 여부의 **기술적 심사** 수행.
- **인공지능처리 연산체계(제2조제3호)**: 데이터로부터 학습·추론하여 예측·분류·생성 등의 출력을 생성하도록 설계된 알고리즘 또는 프로그램.

## 확인 제외 대상 (제3조)
다음은 확인 대상에서 제외되며 신청 시 반려될 수 있다:
1. 법률상 생산·제조·유통이 **금지된** 제품·서비스
2. 전자장치가 아닌 제품 등 인공지능이 활용되지 않았음이 **명백한** 경우
3. **이미 확인이 완료된** 제품·서비스를 구성 변경 없이 **재차 신청**하는 경우

# 절차 (제4조~제8조)

## 신청 (제4조)
확인기관의 장에게 다음을 첨부하여 신청(**온라인 시스템 신청 가능**):
1. 별지 제1호 서식 인공지능 제품·서비스 확인 신청서
2. 별지 제2호 서식 열람·이용동의서
3. 별지 제3호 서식 개인정보 수집·이용 및 제3자 제공동의서
4. 인공지능/인공지능기술의 **배치 및 데이터 흐름도**를 반영한 **제품·서비스 구조도**
5. 알고리즘·데이터 특성·역할 요약이 포함된 **인공지능처리 연산체계 및 기능 명세서**

**② 선행 요건**: 신청 전에 **조달청 목록정보시스템(goods.g2b.go.kr)에 목록화를 요청해 물품목록번호(세부품명번호·식별번호)를 부여받아야 한다** — 이 절차가 공공조달과 직결된다는 점을 보여주는 조항이자, 실무에서 가장 자주 누락되는 선행 요건.

**④⑤ 보완**: 미비 시 **30일 이내 기간**을 정해 보완 요청, 재보완에도 미비하면 반려 가능.

## 기술적 심사 기준 (제5조)
확인기관은 접수 즉시 심사기관에 기술심사를 요청하고, 심사기관은 다음 **7개 기준**으로 심사한다:
1. 제품·서비스에 **인공지능처리 연산체계가 적용**되어 있을 것
2. 적용된 연산체계가 **학습·추론 등 인공지능으로서의 특성**을 가질 것
3. 입력 데이터가 연산체계를 거쳐 **유의미한 결과(예측·생성 등)를 출력**할 것
4. **구조도상 인공지능의 위치가 명확**하고 제품·서비스의 구동 체계와 **결합되어 동작**할 것
5. 연산체계가 제품·서비스의 **기능·편의성·접근성·효율성 등에 활용**되고 있음이 확인 가능할 것
6. 연산체계가 적용된 **주요 기능이 정상적으로 동작**할 것
7. **외부 연산체계와 연동된 경우 호출 로그 또는 API Key를 확인 가능**할 것 — 외부 LLM API를 호출하는 서비스는 이 항목이 핵심 입증 포인트.

## 결정 및 확인서 (제6조·제7조)
- **접수 후 15일 이내 결정**, 복잡성 등 고려 시 **30일 범위에서 1회 연장**(사유·기간 통보).
- 서류 누락·불명확 시 **30일 이내 보완 요청** → 보완일부터 **15일 이내 결정**. 기간 내 보완이 없으면 제출 서류만으로 결정 가능.
- 확인 시 별지 제4호 서식 **「인공지능 제품·서비스 확인서」 발급**, 전자적 보관, **재발급 청구 가능**.
- **일괄 확인서(제7조③)**: 적용된 인공지능은 동일하고 **외형·외관 등 단순 차이만 있는 다른 모델**은 **일괄 기재하여 하나의 확인서**로 발급 가능 — 모델 라인업이 많은 경우 신청 부담을 크게 줄일 수 있다.

## 취소·비밀유지 (제8조·제9조)
- **거짓·부정한 방법**으로 확인받은 경우 확인기관은 확인을 **취소하여야 한다**(기속). 취소 전 **신청자 의견청취** 필요.
- 확인기관·심사기관 임직원은 업무 중 알게 된 비밀·**영업비밀 누설 금지**.

# 실무 체크리스트

- [ ] 공공부문 납품 대상 AI 제품·서비스를 식별하고, **법 제16조제3항 우선구매 고려** 대상이 되기 위한 확인서 취득 필요성 판단.
- [ ] 신청 **이전에** 조달청 목록정보시스템에서 **물품목록번호를 먼저 확보** — 미확보 시 신청 불가(제4조제2항).
- [ ] **제품·서비스 구조도**(AI 배치 + 데이터 흐름)와 **연산체계·기능 명세서**를 심사 기준 7개 항목에 대응되도록 작성.
- [ ] 외부 LLM/API를 호출하는 구조라면 **호출 로그 또는 API Key 확인 가능성**을 사전에 준비(제5조제2항제7호).
- [ ] 외형만 다른 모델군은 **일괄 확인서**로 묶어 신청(제7조제3항).
- [ ] 처리 일정 역산: **접수 후 15일**(+30일 연장 가능), 보완 발생 시 보완일부터 15일.
- [ ] 신청서에 **영업비밀** 포함 시, 제9조 비밀유지의무를 전제로 제출 범위를 검토.
