## 1. 이 세션의 목적과 결론

목적: 대회 입상 뒤 대시보드·텔레그램을 널리 공유하기 전에 **Anthropic 토큰이 새는 자리를 막고 권한을 정리**하는 것.

결론(2026-09-08 실측):
- **비로그인 사용자**는 토큰을 거의 못 쓴다. 유일한 경로는 국회 발언 검색의 규칙 파서 실패 시 Haiku 보정(건당 약 1원).
- **승인 계정**이 쓰던 Sonnet 비스트리밍 경로(용어 재생성·관계도 생성·이슈 영향 요약·과거 뉴스 보강·연결 테스트)는 전부 **관리자 전용**으로 내렸다. 승인 계정에 남은 것은 AI 자문, 법령 DIFF 수동 분석(자문 한도 차감), 뉴스 영향 분석 "다시 분석"(Haiku).
- 프록시 한도 종류는 **모델명**으로 서버가 정한다(`/sonnet/i` → 자문 한도, Haiku → 300/일 백스톱). 클라이언트 헤더는 믿지 않는다. ※ 다른 세션 #152가 그 뒤 Haiku 한도를 100/일+60/시간으로 더 내렸다.
- 브라우저가 스스로 Sonnet을 부르는 경로(용어 자동 추출·상세 백필)는 없앴다. 05:00 KST GitHub Actions `term_extract.yml`(pg_cron `term-extract-trigger`)이 대신한다.
