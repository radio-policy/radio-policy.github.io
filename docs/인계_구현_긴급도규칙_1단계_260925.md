## 1. 공용 매처 (먼저 — 사내판이 그대로 복사한다)

1. `urgency_rules.py` (저장소 루트, 표준 라이브러리만)
   - `normalize_text(title, summary) -> str` = `unicodedata.normalize('NFC', f'{title} {summary or ""}')`
   - `match_urgency_rules(rules, title, summary) -> dict | None` — `position` 순 첫 적중 `{id, mode, level}`. 적중 = `any` 하나 이상 AND `and_any` 각 그룹 하나 이상(평면이면 그룹 하나) AND `none` 없음. 부분 문자열, 대소문자 그대로.
   - `apply_urgency_rules(rules, title, summary, ai_level) -> (level, rule_id|None, changed: bool)` — set: `(level, id, level!=ai)`; min: `(max(ai, level), id, 바뀜여부)`; 미적중 `(ai, None, False)`. 등급 순서 참고<보통<긴급.
   - `validate_rules(rows) -> list[str]` 오류 문장 목록(id 중복·mode/level 값·any 비어 있음·and_any 형식).
   - `URGENCY_RULES_FALLBACK` = D8 5개 규칙(§2 표) — 표 조회 실패 시 비상용.
2. `supabase/functions/_shared/urgency_rules.js` — plain JS(ESM 아님, `cite_verify.js`와 같은 방식으로 `window`/`globalThis`에 붙임), 같은 함수 3개 + `String.prototype.normalize('NFC')`.
3. `tests/fixtures/urgency_rules_cases.json` — `[{name, rules, title, summary, ai, expect:{level, rule_id, changed}}]`. 필수 케이스: ① 걸려야 하는 제목 3(「[2026 국감 증인-과방위①] SKT·KT 보안책임자 증인석…」, 「이통3사·듀오·티빙…'유출'기업 대거 국감소환」, 「통신 3사, CISO급 나란히 국감행…」) ② 걸리면 안 되는 3(「KT, 국감서 보안체계 점검…이상운 CISO 증인 채택」, 「SK텔레콤 독과점…해킹에 흔들린 아성 [연도별 국감]」, 「[2026 국감] 통신3사, '보안 투자' '소비자 혜택 축소' 쟁점」) ③ min이 긴급을 내리지 않음 ④ set이 내림 ⑤ none 제외 ⑥ 첫 적중 min이 이미 그 이상 → 값 그대로·id 기록·뒤 규칙 미적용 ⑦ NFD 입력 1건 ⑧ 평면 and_any ⑨ min+AI 높음→AI 값 ⑩ min+AI 낮음→하한 ⑪ set→set 값. `team_id`는 넣지 않는다.
4. 테스트: `tests/test_smoke.py`에 `TestUrgencyRules`(케이스 파일 전건 Python) + `tests/urgency_rules.test.js`(node, 같은 파일 JS). `python -m unittest discover -s tests`, `node tests/urgency_rules.test.js`.

## 2. DB (Supabase MCP는 읽기 전용 — DDL은 `apply_migration` 또는 sb_client/psql)

```sql
alter table public.news_feed add column if not exists urgency_rule text;   -- null = 미적중. authenticated 컬럼 UPDATE 권한(8칸)에 넣지 않음
create table public.urgency_rules ( … §3 DDL 그대로 … );
alter table public.urgency_rules enable row level security;
create policy urgency_rules_sel on public.urgency_rules for select to anon, authenticated using (true);
create policy urgency_rules_ins on public.urgency_rules for insert to authenticated
  with check (is_admin() or (team_id is not null and is_leader() and team_id = my_team()));
create policy urgency_rules_upd on public.urgency_rules for update to authenticated
  using (is_admin() or (team_id is not null and is_leader() and team_id = my_team()))
  with check (is_admin() or (team_id is not null and is_leader() and team_id = my_team()));
-- DELETE 정책 없음(삭제 = enabled=false만)
grant select on public.urgency_rules to anon;
grant select, insert, update on public.urgency_rules to authenticated;
grant all on public.urgency_rules to service_role;
```

## 3. 크롤러 `crawler.py`

- `load_urgency_rules()` — `load_news_criteria()`(1128행) 패턴. `urgency_rules` 표에서 `enabled and team_id is null`을 `position` 순으로 → `validate_rules` → 실패·0건이면 FALLBACK. 로그 `[규칙] N개 로드(db|fallback)`. 실행당 1회(모듈 전역 캐시).
- `save_new_items` 루프(현재 1615~1618행, `val = classify_urgency(...)`): 설계안 §4-1 3번 코드 그대로 — 규칙 먼저, set이면 콜 생략, min이면 콜 뒤 max, `item['urgency_rule']` 모든 행에 키. 요약은 `_URGENCY_SUMMARY.get(url, '')`.
- 로그 `[규칙] 적중 N건 (id×n …, 값 변경 M건, AI 생략 K건)`.
- `_URGENCY_CRITERIA`(70행~): 즉시대응 목록 「침해사고·장애·유출」 항목 끝(⚠️ 회고 줄 뒤)과 「제도가 실제로 움직인 것」 사이에 D6 문장(설계안 §4-1 6번 인용문) 삽입. 그 뒤 `importance_feedback` 53건 세션 재채점(API 0회) 결과를 배경역사에 한 줄.
- 알림·큐·브리핑 코드 변경 없음(저장값 사용). `api_usage`·캐시 블록 구조 무변경.

## 4. 대시보드 `app.js` / `index.html`

- `NEWS_LIST_COLS`(3777행)에 `urgency_rule` 추가. 목록 로드 때 `urgency_rules`(공통, enabled 무관) 1회 조회 → id→note 맵; `importance_feedback`(`news_id` 목록, order+range) 1회 조회 → 담당자 수정 집합.
- 상세 모달 배지 옆(4396행 부근): `AI 판정` / `규칙: <note>` / `담당자 수정`. `escHtml` 필수(#191).
- 설정 탭 「긴급도 규칙」 카드 — `press_keywords` 카드(7379~7479행) 복제. 탭 「공통 | 내 팀(회색, "팀별 등급 저장이 열리면 사용")」. 행 편집(any/and_any/none 칩 입력, mode·level 선택, note, enabled, position), **id 자동 생성·수정 시 잠금**, 저장 = upsert(`is_admin()` 게이트는 안내용, 관문은 RLS). 「최근 기사에 적용해 보기」 = `urgency_rules.js` 매처를 `newsDataCache` 제목+`summary`에 돌려 적중 목록·값 변경 건수 표시(저장 전). `data-login-only` + `data-admin-only`.
- `index.html`: `<script src="supabase/functions/_shared/urgency_rules.js?v=YYYYMMDDa">` 추가(cite_verify.js 옆), `app.js?v=` 갱신(현재 값 먼저 확인). `.gitlab-ci.yml` 11행 cp 목록과 `tools_release.py` `STATIC`에 추가. `node --check app.js`.
