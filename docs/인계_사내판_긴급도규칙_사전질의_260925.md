# [사내판 인계 — 사전 질의·예고] 뉴스 긴급도 낱말 규칙 층 + 팀별 규칙 편집기 (2026-09-25)

받는 곳: 맥북 사내판 세션(radio-policy-internal). 보내는 곳: 외부판 세션(설계안 `docs/뉴스중요도_공통팀별_설계안_260925.md`, 승인 대기).
이 문서는 **예고와 질문**이다. 형식·코드는 운영자 승인(D1~D7) 뒤 확정되며, 그때 본 인계문을 따로 보낸다. 지금은 아래 질문 3개에 답을 주면 외부판 구현과 병렬로 준비할 수 있다.

## 1. 무엇이 바뀌나 (요약)

- 외부판 크롤러의 긴급도 판정 뒤에 **낱말 규칙 층**이 붙는다. 규칙은 코드가 아니라 DB 표 `urgency_rules`(행 = 규칙, `team_id` null = 공통)에 두고, 대시보드 편집기에서 고친다.
- 첫 공통 규칙: SK텔레콤(통신3사 일괄 포함) + 국감/국정감사 + 증인·참고인·소환·출석 → **최소 긴급**. 09-15~25 실측 11건 적중·오탐 0.
- 적중한 기사는 `news_feed.urgency_rule`(규칙 id)에 남고, 화면 배지 옆에 `AI 판정 / 규칙: <note> / 담당자 수정` 출처가 붙는다.
- **운영자 결정(2026-09-25): 사내 콘솔에도 팀별 규칙 편집기를 둔다.** 원칙은 "규칙 하나에 주인 하나":
  - 공통 규칙 — 주인은 외부 대시보드 관리자. 사내는 다리로 받아 **읽기 전용**(사내 편집기에서 회색, "외부 대시보드에서 관리").
  - 사내 팀 규칙 — 주인은 사내 콘솔의 그 팀. 사내 등급(`news_grade.py`)에만 적용, 외부로 올라가지 않는다(외부 DB에 사내가 쓰는 경로는 만들지 않는다 — anon 쓰기·서비스 키 사내 보관 모두 금지).
  - 외부 팀 규칙(외부 2단계) — 사내는 쓰지 않는다.
- 판정 함수와 형식은 **외부판 파일을 그대로 이식**한다: `urgency_rules.py`(Python), `supabase/functions/_shared/urgency_rules.js`(plain JS), `tests/fixtures/urgency_rules_cases.json`(제목·요약·AI등급 → 기대 등급·규칙 id). 사내도 같은 케이스 파일로 검증한다.

## 2. 규칙 형식 초안 (D1 승인 전 — 바뀔 수 있음)

```json
{
  "id": "skt_gukgam_witness",
  "team_id": null,
  "position": 10,
  "mode": "min",                 // min = 올리기만, set = 지정
  "level": "긴급",
  "any": ["SK텔레콤", "SKT", "통신3사", "이통3사", "통신 3사", "이통 3사", "이동통신 3사"],
  "and_any": [["국감", "국정감사"], ["증인", "참고인", "소환", "출석", "국감행", "국감장"]],
  "none": [],
  "note": "국정감사 증인·참고인 채택·소환·출석 — 전 팀 공통 긴급",
  "enabled": true
}
```

판정: `any` 하나 이상 AND `and_any` **각 그룹**마다 하나 이상 AND `none` 없음. 평면 `and_any`는 그룹 하나로 해석. 대상 텍스트는 **제목 + 요약만**(본문 금지 — 과거 사례 언급 오탐). `position` 오름차순으로 첫 적중 규칙이 정한다. `min`은 AI 등급보다 높을 때만 올린다.

## 3. 질문 (답 주세요)

1. **다리가 옮기는 컬럼**: `export_news.py`가 `news_feed`에서 어느 컬럼을 사내로 옮기는지(전체 `*`인지 명시 목록인지). 새 컬럼 `urgency_rule`을 옮길 수 있는지 — 옮기면 사내 콘솔 출처 표시에 그대로 쓴다. 옮기지 않아도 무해.
2. **사내 팀 표**: 사내 DB의 팀 표 이름·키(외부는 `teams.id smallint`). 사내 `urgency_rules` 표의 `team_id` FK를 거기에 걸어야 한다. 사내 콘솔에 "내 팀"과 "팀장" 개념(외부 `profiles.role='leader'` 대응)이 있는지.
3. **`news_grade.py` 삽입 지점**: 팀별 AI 판정 결과를 저장하는 자리(함수·행)와, 판정 재료로 제목·요약을 어떤 변수로 갖고 있는지. 규칙 층은 그 직전에 `apply_urgency_rules(rules, title, summary, ai_val)` 한 줄로 들어간다. 공통 규칙은 공통 판정에, 사내 팀 규칙은 해당 팀 판정에 각각 적용.

추가로 있으면: 다리가 외부 표를 anon 키로 읽는 목록에 `urgency_rules`(공통 행)를 추가하는 데 걸림돌이 있는지(외부는 anon SELECT를 열 예정 — 낱말 목록이라 비밀 아님).

## 4. 아직 하지 말 것

- 형식이 승인 전이라 **코드를 먼저 쓰지 말고** 질문 답과 삽입 지점 파악까지만. 본 인계(DDL·매처 두 파일·케이스 파일·편집기 UI 요구·다리 반입 추가)는 외부판 1단계 구현과 함께 보낸다.
- #180 원칙("알림 대표 판정은 외부 한 곳, 사내는 옮기기만")은 그대로다. 이번 건은 **등급 판정**(이미 사내가 따로 하는 것)에 규칙 층을 붙이는 것이며, 공통 규칙을 사내가 따로 만들지 않음으로써 취지를 지킨다.
