# SKT 이동통신사업(MNO) 관점 법령 지식베이스 확충 제안 보고서

- 작성일: 2026-07-30 / 작성: 전파정책AI (딥리서치 에이전트, 법제처 DRF API + 웹 조사)
- **검증 기준**: 법제처 국가법령정보 DRF API(law.go.kr, 2026-07-30 조회)로 전 후보의 현행 여부·정확한 법령명·공포(발령)번호·시행일을 확인. 행정규칙은 발령번호·발령일 기준(지식베이스 문서명 규약과 동일). 보유 여부는 Supabase `document_chunks`(status='current') 실측 기준.
- **주의**: 제안만 담은 문서다 — 어떤 법령도 아직 다운로드·적재하지 않았다(운영자 지시).

## 0. 현재 보유분 요약 (법령형 문서만)

- **전파법 계열**: 전파법·시행령·시행규칙 + 전파법 시행에 관한 방미통위 규칙 + 무선국 운용·검사·전파관리세칙 등 고시 다수, 주파수 분배표·할당 고시 4종, 기술기준 고시 12종, 전자파 고시 9종, 적합성평가 고시 11종
- **전기통신사업법 계열**: 법·시행령 + 시행에 관한 과기정통부규정 + 단말장치 유통 과징금 고시(방미통위 2026-6) — **하위 고시가 이 3건뿐인 것이 최대 공백**
- **방송통신발전기본법 계열**: 법·시행령·기금규정·설비기술기준(대통령령)·안전성신뢰성 고시 등 6종
- **정보통신망법**: 법·시행령·시행규칙 (하위 고시 없음)
- **재난안전법**: 법·시행령·시행규칙
- **일반**: 지방세법 2, 국가재정법 2, 국가회계법 2, 부담금관리기본법 2, 정부조직법, 정보통신산업진흥법 3
- 참고: 전기통신사업법 시행규칙은 현행 법령으로 존재하지 않음(DRF 확인) — 공백 아님

## 4. 폐지·통합 법령 경위 (오답 방지용 명시)

1. **단통법(이동통신단말장치 유통구조 개선에 관한 법률) — 폐지 확인**. 2025-07-22 폐지 시행(폐지법률은 2024-12 국회 통과). 지원금 공시의무·유통점 추가지원금 상한(15%) 폐지, 이용자 차별금지·선택약정 25% 요금할인 등은 **전기통신사업법으로 이관**. 지원금 관련 4개 고시(요금제별 차별 기준, 전환지원금 기준, 공시·게시 방법, 요금할인 혜택 제공 기준)는 폐지되었고, 현행 후속 고시는 6건(과징금〔보유〕·사전승낙서·자료제출·중고안심거래·분실도난확인·식별번호공유). DRF에서 단통법 검색 0건으로 폐지 교차 확인.
2. **방송통신위원회의 설치 및 운영에 관한 법률 → 방송미디어통신위원회의 설치 및 운영에 관한 법률**(법률 제21379호, 시행 2026-02-19). 2025-10-01 정부조직 개편으로 방통위 폐지·방미통위 출범, 과기정통부의 유료방송 인허가 등도 이관. 통신 규제 고시 다수가 2026년 방미통위 명의로 재발령(제2026-11호 일괄 등) — 적재 시 소관·발령번호를 방미통위 기준으로 잡을 것.
3. **요금인가제**: 2020년 유보신고제 전환 이후에도 「이용약관 인가대상 기간통신서비스와 기간통신사업자」 고시는 2026-04-28 재발령되어 현행(신고 심사 대상 지정 기능). 폐지된 것으로 오인하지 말 것.
4. **전기통신기본법**: 폐지되지 않고 존치(현행 법률 제16019호). 기능 대부분이 방송통신발전기본법 등으로 이동했을 뿐.
