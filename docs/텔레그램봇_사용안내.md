# 정책 AI도우미 — 텔레그램 봇 사용 안내

SKT Comm센터 기술정책팀의 통신·전파 정책 모니터링 봇입니다.
매일 아침 브리핑을 받고, 궁금한 법령을 바로 찾아볼 수 있습니다.

---

## 1. 시작하기

아래 링크를 열고 **`/start`** 를 누르면 끝입니다.

**https://t.me/radio_policy_law_ai_bot**

설정 키보드가 나오면 원하는 항목만 켜 두세요.

---

## 2. 무엇을 받나요

| 항목 | 내용 |
|---|---|
| 📋 **모닝 브리핑** | 하루 1회. 주요 뉴스 + SKT 관점 주목 포인트 |
| 📡 **주요 뉴스** | 대응이 필요한 뉴스가 생기면 전달 (과징금·소송·장애·규제 등) |
| 🏛️ **국회 법안** | 신규 발의 법안, 입법예고 시작 |

세 가지를 각각 켜고 끌 수 있습니다. **모두 끄면 알림이 오지 않습니다.**

### 받는 시각

- **시작 시각**(오전 6~10시 중 선택) — 이 시각부터 받습니다
- **종료 시각**(오후 6~10시 중 선택) — 이 시각을 넘기면 **다음 날 아침까지 조용합니다**

밤사이 생긴 소식은 사라지지 않고 **다음 날 시작 시각에 모아서** 옵니다.

설정을 바꾸려면 언제든 **`/settings`**

---

## 3. 법령 찾기 — `/law`

**승인 없이 바로 쓸 수 있습니다.**

### 주제로 찾기 (가장 많이 쓰는 방법)

조문 번호를 몰라도 됩니다. 궁금한 것을 그냥 쓰세요.

```
/law 리파밍 관련 법 조항이 어떤게 있지?
/law 3G 종료하려면 어떤 절차가 필요한가
/law 개인정보 유출되면 언제까지 신고해야 하나
```

→ 관련 법령·조항을 **법률 → 시행령 → 고시 순서로** 찾아 이유와 함께 알려줍니다.

### 조문 번호를 알 때

```
/law 전기통신사업법 19조
/law 전파법 6조의2
```

→ 조문 원문이 바로 나옵니다. (AI를 안 거쳐서 즉시 응답)

약칭도 됩니다 — `정보통신망법`, `개인정보보호법`, `위치정보법`, `단통법`, `방발법` 등

---

## 4. AI 자문 — `/ask`

**뉴스·동향·시사점까지 종합한 답변**이 필요할 때 씁니다.

```
/ask 일본 28GHz 주파수 활용현황 정리해줘
/ask 5G 과장광고 소송이 우리한테 어떤 영향이 있나
```

명령어 없이 그냥 질문만 써도 자문으로 연결됩니다.

> ⚠️ **최초 1회 운영자 승인이 필요합니다.** 처음 쓰면 승인 요청이 자동으로 가고,
> 승인되면 그 뒤로는 바로 쓸 수 있습니다. (하루 20회)

### `/law` 와 `/ask` 무엇이 다른가

| | `/law` | `/ask` |
|---|---|---|
| 답하는 것 | **법령 조문만** | 법령 + 뉴스 + 동향 + 시사점 |
| 승인 | 불필요 | 최초 1회 필요 |
| 하루 한도 | 10회 | 20회 |
| 걸리는 시간 | 약 20초 | 1~2분 |

**법이 어떻게 돼 있나** → `/law`
**그래서 어떻게 봐야 하나** → `/ask`

## 5. 명령어 정리

| 명령어 | 하는 일 |
|---|---|
| `/start` | 구독 시작 · 설정 키보드 |
| `/settings` | 받을 항목·요일·시각 변경 |
| `/law 질문` | 법령·조문 검색 |
| `/ask 질문` | AI 자문 (승인 필요) |
| `/stop` | 모든 알림 끄기 (설정은 보존) |

## 6. 알아두면 좋은 것

**이어지는 질문은 안 됩니다.** 봇은 앞의 대화를 기억하지 않으니, 질문 하나하나를 완결해서 쓰세요.

- ❌ `/ask 5G 재할당 대가는?` → `/ask 그건 언제 시행되나?`
- ✅ `/ask 5G 주파수 재할당 대가 산정 기준의 시행일은?`

**답이 이상하면 알려주세요.** 실무에서 쓰는 말과 법령 용어가 달라 못 찾는 경우가 있습니다
(예: 「리파밍」은 법에 없고 「주파수재배치」로 쓰입니다). 그런 사례를 알려주시면 바로 보완합니다.
